## ما هذا المستودع

التنفيذ المرجعي لدولة رقمية ملكية فدرالية: الملك هو صاحب السيادة الوحيد، وكل ما دونه وكلاء رقميون
يعملون تحت مرور بوابة التاج، بسجل تدقيق غير قابل للمحو، وصلاحيات محدودة، وإيقاف فوري.

المستودع مبني على ثلاث وثائق تأسيسية موجودة في [`docs/specs/`](docs/specs/) وهي **مصدر الحقيقة**:

| الوثيقة | الدور |
|---|---|
| [`digital-absolute-federal-monarchy-spec.md`](docs/specs/digital-absolute-federal-monarchy-spec.md) | المواصفة التأسيسية — 52 قسمًا: السيادة، المؤسسات، الحقوق، الأمن |
| [`digital-monarchy-comprehensive-spec.md`](docs/specs/digital-monarchy-comprehensive-spec.md) | المواصفة الشاملة — أبواب تفصيلية للحكم والوكلاء والبنية والاقتصاد |
| [`digital-state-build-guide.md`](docs/specs/digital-state-build-guide.md) | دليل البناء — شجرة الملفات، التبعيات، المراحل، الاختبارات |

الوثائق ليست للقراءة فقط: هي **توجيهات تنفيذية**. خريطة تحويلها إلى وحدات ومالكين في
[`docs/DIRECTIVES.md`](docs/DIRECTIVES.md).

## ترتيب الاعتماد المعماري (لا يُعكس)

```
الملك والهوية → جذر الثقة → بوابة التاج → السجل والمراقبة والإيقاف
   → النماذج → مصنع الوكلاء → الحكومة → الأقاليم → الاقتصاد والخدمات
   → الاتصال الخارجي → التوسع → التدقيق المستقل → إعلان 100%
```

## التشغيل والاختبار

```bash
npm install        # بلا تبعيات تشغيل خارجية — أدوات البناء فقط
npm run build      # تحقق الأنواع وبناء TypeScript
npm test           # تشغيل كل اختبارات القبول
npm run verify     # بناء + اختبار + التحقق من سلامة سجل التدقيق
```
