# دليل تشغيل التعافي من الكارثة — المرحلة 32

> **RULE-003:** لا استعادة إدارية ولا تبديل مباشر للقرص. القرار ملكي، والتنفيذ يمر حصرا عبر `archive_restore` ثم `RoyalArchive`.

## الأدوار والأهداف

| الدور | مسؤوليته |
|---|---|
| التاج | يصدر أمر `archive_restore` الموقّع للنسخة المحددة. |
| وزارة البنية | تعلن الانقطاع، تحدد الملف، تشغل `scripts/restore.sh`، وتجمع الدليل. |
| ديوان التدقيق | يراجع سلسلة التدقيق، الحجم، وزمن التنفيذ، ولا يعلن عودة `full`. |
| مسؤول التشغيل | يقرر لاحقا فك التجميد أو العودة إلى `full` بقرار معلن مستقل؛ السكربت لا يفعل ذلك. |

السياسة في `config/recovery.yaml`: **RTO=30 ثانية**، **RPO=60 ثانية**، فاصل النسخ **30 ثانية**، احتفاظ **3** نسخ، والتحقق بعد الاستعادة **إلزامي**.

## قبل الاستعادة

1. أعلن الانقطاع وسببَه، وانقل الاستمرارية إلى `limited` أو `halted` وفق القرار؛ لا تخمّن نجاحا.
2. أوقف أي مشغل نسخ متزامن وحدد ملفا من مجلد `backup_directory` المعلن؛ لا تنقل ملفا من مسار غير معلن.
3. افحص أن اسم الملف ومجلده يطابقان السياسة، واحفظ نسخة جنائية من الملف خارج مسار التشغيل عند الحاجة.
4. احصل على أمر تاجي صالح بالفعل `archive_restore` للمعرف داخل الغلاف. لا يملك مسؤول التشغيل استبداله بأمر إداري.

## التنفيذ

```bash
npm run build
bash scripts/restore.sh <مجلد-التهيئة> <ملف-النسخة>
```

يقرأ السكربت الغلاف من القرص، ويوقع أمرا في عملية الدولة الجديدة، ثم يجعل `RecoverySnapshotStore` يتحقق من الغلاف و`RoyalArchive` يتحقق من بصمة الحمولة. الترتيب غير قابل للتبديل: **تحقق البصمة ← تجميد التوالد ← نسخة أمان ← تبديل ذري ← `verifyIntegrity()` بعدي**.

## نجاح الاستعادة

لا تعلن النجاح إلا عند اجتماع الآتي:

1. ينتهي السكربت برمز صفر ويطبع «استعادة ناجحة».
2. لا يظهر `RECOVERY_SNAPSHOT_TAMPERED` أو `RECOVERY_ARCHIVE_TAMPERED` أو رفض تاجي.
3. `npm run verify` يعلن سلامة السجل، وتطابق جواهر النسخة: السكان، الشرائح، حصص `identity_slots`، المهام، الوزارات، العقود، والذاكرة والمعرفة.
4. يبقى التوالد مجمدا ووضع الاستمرارية `limited`. لا يتحول إلى `full` ولا ينفذ `thaw` تلقائيا.
5. يسجل ديوان التدقيق زمن البدء والنهاية وحجم النسخة ويقارنه بـRTO وRPO في التقرير التشغيلي.

## عند الفشل

- **ملف مفقود أو مسار غير معلن:** لا تبحث في مسارات بديلة؛ صحح الإعلان أو اختر نسخة معلنة أخرى.
- **تحريف الغلاف أو الحمولة:** ارفض الملف، احتفظ به للدليل، واختر نسخة احتفاظ أقدم سليمة؛ لا تعطل التحقق.
- **أمر تاجي مرفوض أو قديم:** اطلب أمرا جديدا؛ لا تتجاوز البوابة.
- **فشل استيراد أو تحقق بعدي:** يعيد الأرشيف حالة الأمان السابقة ويبقى التوالد مجمدا والاستمرارية `halted`. لا تستأنف الخدمة؛ وثق سبب الرفض وارفعه للتاج وديوان التدقيق.
- **تجاوز RTO:** لا تخفف الهدف. سجل الزمن الحقيقي، أبق الوضع `halted`، وافتح بندا تشغيليا قبل إعلان الاستعادة مكتملة.
