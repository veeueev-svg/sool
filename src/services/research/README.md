## صيغةُ ما يُكتب فيه

1. **رأس ملف** بالصيغة الإلزامية (`docs/DIRECTIVES.md` §4) ثم قائمة **«ثوابت هذه الوحدة»** مرقّمة.
2. **لا وحدة فوق 400 سطر** — السقف في `config/module_limits.yaml` ويُنفَّذ بـ`npm run check:size`.
3. **التفكيك نقلٌ حرفيّ**: لا إصلاح ولا تحسين في أثنائه، وواجهةُ التصدير تبقى
   [`../human_research.ts`](../human_research.ts) فلا يُعدَّل مستوردٌ ولا اختبار — والدليلُ
   خطُّ الأساس نفسه أخضر بعده (**1824/1824**).
4. **الحرَسُ لا يكتب سجلًّا**: يرجع سببًا، ويقيّده صاحبُ الدور بحدثه المعلن.
