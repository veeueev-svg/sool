## 4) الفحص العدائي للعيب المسمّى وقياس الطفرات

### أ) فحص عيب الجلسة 8: `RATE_AMENDMENT_APPEND_MUTABLE_REFERENCE_ESCAPE`

1. **طبيعة العيب السابق:**
   في الجلسة 8، تبيّن أنّ علاج الجلسة 7 اقتصر على دوال الاستعلام الأربع (`historyOf`, `firstOf`, `currentFor`, `effectiveAt`) لكنه أهمل:
   - دالة `RatePolicy.append()` التي كانت تدفع كائن `declaration` في مصفوفة التاريخ ثم تعيد نفس المرجع الحي (`return declaration;`).
   - دالة `RevenueService.amendRate()` التي كانت تعيد هذا المرجع الحي في `result.declaration`. وكان أي مستدعٍ يستطيع تعديل `result.declaration.ratePerMille = 999` فيتغيّر السعر الداخلي المعتمد للرسم دون أمر ملكي ودون قيد في السجل الأبدي.
   - المُنشئ `new RatePolicy(rates)` الذي كان يحتفظ بمراجع الكائنات الخارجية الممررة إليه مباشرة في `this.history`.

2. **التحقّق من المعالجة الجذرية في الشفرة:**
   في الالتزامة المدموجة `75cdece` (ضمن الفرع المدموج في #73):
   - في `src/economy/rate_policy.ts` (السطر 68):
     ```ts
     constructor(rates: readonly RateDeclaration[]) {
       for (const rate of rates) this.history.set(rate.base, [{ ...rate }]);
     }
     ```
     أصبح المُنشئ ينسخ كائنات الإعلان الواردة إليه سطحيًّا عبر `[{ ...rate }]`، وبما أنّ حقول `RateDeclaration` كلها أولية (`base: string`, `ratePerMille: number`, `declaredAt: number`)، فإنّ النسخ السطحي هنا بمثابة نسخ عميق كامل، وبذلك انقطعت صلة الكائن الداخلي بأي مرجع خارجي للمُدخلات.
   - في `src/economy/rate_policy.ts` (السطر 108):
     ```ts
     append(base: string, ratePerMille: number, declaredAt: number): RateDeclaration {
       const declaration: RateDeclaration = { base, ratePerMille, declaredAt };
       const h = this.history.get(base);
       if (!h) throw new Error(`RATE_BASE_UNDECLARED:${base}`);
       h.push(declaration);
       return { ...declaration };
     }
     ```
     تُدفع النسخة في `h`، بينما يُعاد للمستدعي كائنٌ جديد مستقل تمامًا `{ ...declaration }`.
   - في `src/economy/tax.ts` (السطر 346):
     ```ts
     return { ok: true, declaration, previous: current, auditId: entry.hash };
     ```
     حيث `current` قادم من `currentFor` (التي تعيد `{ ...d }`) و`declaration` قادم من `append` (التي تعيد `{ ...declaration }`). كلاهما نسخٌ مستقلة.

3. **قياس الطفرات الميداني على `dist/`:**
   - **طفرة 1 (إرجاع المرجع الحي في append كالسابق):**
     عُدِّل `dist/src/economy/rate_policy.js` ليُعيد `return declaration;` بدلاً من `return { ...declaration };`.
     عند تشغيل اختبار الوحدة:
     ```bash
     node --test dist/tests/economy/tax_rate_amendment.test.js
     ```
     سقط الاختبار رقم 18 فورًا:
     `not ok 18 - **T-53/مجلس 8** — RATE_AMENDMENT_APPEND_MUTABLE_REFERENCE_ESCAPE: amendRate يُعيدُ نسخةً لا مرجعًا حيًّا`
     مع الخطأ: `AssertionError: المرجعُ المُعاد نسخةٌ لا أصل — التعديلُ بلا أمرٍ ملكيٍّ لا يصل (expected: 40, actual: 999)`.
     النتيجة: `tests 18 · pass 17 · fail 1`. الطفرة قُتلت بالتمام.
   - **طفرة 2 (مسبار على مُدخلات المُنشئ):**
     أُجري مسبار مستقل على `RatePolicy` حيث تمّ إنشاء سياسة بمصفوفة كائنات، ثم تمّ تعديل حقول الكائنات في المصفوفة الأصلية (`input[0].ratePerMille = 999; input[0].base = "hacked"`). أثبت المسبار أنّ `policy.currentFor("compute").ratePerMille` ظل ثابتًا عند 25، وأنّ `policy.declares("hacked")` عاد بـ `false`.

### ب) التثبّت من عدم وجود أي مسار تسريب مرجع حي آخر

فُحصت كافة واجهات الاستعلام والإرجاع والتعديل في نطاق البند:
- `RatePolicy.historyOf(base)`: تعيد `h.map((d) => ({ ...d }))` (مصفوفة جديدة وعناصر مستنسخة).
- `RatePolicy.firstOf(base)`: تعيد `{ ...d }` أو `null`.
- `RatePolicy.currentFor(base)`: تعيد `{ ...d }` أو `null`.
- `RatePolicy.effectiveAt(base, at)`: تعيد `{ ...effective }` أو `null`.
- `RatePolicy.declaredBases()`: تعيد `[...this.history.keys()]` (مصفوفة جديدة بمفاتيح نصية أولية).
- `RatePolicy.append(...)`: تعيد `{ ...declaration }`.
- `RatePolicy.restore(...)`: تدفع كائنًا حرفيًّا جديدًا `{ base, ratePerMille, declaredAt }` ولا تحتفظ بمرجع كائن الشاهد.
- `RevenueService.amendRate(...)`: تعيد `{ ok: true, declaration, previous, auditId }` وكلها كائنات مستنسخة.
- `RevenueService.rateFor(...)`: تعيد كائنًا مستنسخًا.
- `RevenueService.rateHistoryOf(...)`: تعيد مصفوفة مستنسخة بعناصر مستنسخة.

أُجري مسبار شامل عبر بيئة Node.js حاول تعديل كل مرجع مُعاد من كل دالة من هذه الدوال، وتأكد أنّ جميع الحالات الداخلية بقيت معزولة تمامًا وغير قابلة للاختراق أو التبديل بغير مسار الأوامر الملكية وبوابة التاج والسجل الأبدي.
