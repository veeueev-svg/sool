## 4) العيوب المسماة — نقل الجنس لا إغلاق الجذر

السؤال الذي طُلب مني: هل عولجت الستة من الجذر أم نُقلت؟ القياس: الحرف المغلق هو «الأساس معرّف مهيّؤه كائن حرفي» أو «الحرفي في التعبير نفسه بمفتاح معرّف» أو «الاستيراد المسمّى لمتغير له مهيئ» أو «النداء المباشر الذي يحلّ توقيعه إلى دالة في ملف `.ts`». ما دون ذلك يعود أخضر، والتشغيل يكتب `archive_snapshot`. كل وجه أدناه ملف `.ts` تحت `src/data/` داخل البرنامج (تشخيصات النوع والنحو على ملفات المسبار: 0)، و`opaqueCodeReason` على النداء الذي ينفّذ النص أعاد `null`. البوابة EXIT=0 بلا `[RC-14]`. التشغيل حيث أعدته كتب الصنف. الخام في `probes/probe-results.jsonl`.

الآلة ما زالت قائمة أشكال أوسع. الشاهد العكسي في الضوابط أعلاه يثبت أنها ترى الصيغة المسماة وتخضرّ أختها.

### RC14_ARRAY_VARIABLE_INDEX_LOSES_ELEMENT

`literalRootOf` يقبل كائنًا حرفيًا أو `Object.assign` فقط (`rehydrate_value_origin.ts` نحو 295–304). فهرس المصفوفة يُنزل إلى العنصر فقط إذا كان الأساس نفسه `ArrayLiteralExpression` والمفتاح يطابق `/^\d+$/` (نحو 281–284). لذلك `const box = { run: eval }; box.run` يسقط، و`const arr = [eval]; const evil: any = arr[0]; evil("globalThis.j.record('archive_snapshot', {})")` يخرج 0 والتشغيل كتب الصنف. النقل نفسه: `[eval].at(0)` و`[eval].map((x: any) => x)[0]` — EXIT=0 والتشغيل كتب. هذا نقل لـ`RC14_INLINE_LITERAL_EXTRACTION_GREENS` لا حدًّا مكتوبًا: الحرف `[eval][0]` أُغلق، والمتغير الذي يحمل المصفوفة باب.

### RC14_DESTRUCTURE_AND_FOROF_FROM_BINDING_LOSE_MEMBER

الماسح يربط عضو التفكيك أو عنصر for-of فقط إذا كان المهيئ حرفيًا في التعبير نفسه (`rehydrate_binding_flows.ts` نحو 43–66 و78–91). وإلا يربط الاسم بالمهيئ كاملًا، و`originOf` على كائن حرفي أو مصفوفة يسقط إلى `data` (نهاية `originOf` نحو 128). الوجهان:

- `const box = { run: eval }; const { run }: { run: any } = box; run(…)` — EXIT=0، التشغيل كتب.
- `const arr = [eval] as any[]; for (const run of arr) run(…)` — EXIT=0، التشغيل كتب.

التفكيك والحلقة المضمّنان يسقطان (الضابط). القناة المعلنة «التفكيك وعنصر for-of» أُغلقت لحرفيّ التعبير لا للربط داخل الملف. نقل لـ`RC14_BINDING_CHANNELS_LOSE_MEMBER_ORIGIN`.

### RC14_COMPUTED_AND_NESTED_LITERAL_EXTRACTION

`propertyNameText` لا يطوي المفتاح المحسوب، و`objectLiteralMemberOrigin` يسأل الاسم لا التعبير المطوي (نحو 335–337). `const evil: any = ({ ["run"]: eval }).run; evil(…)` — EXIT=0، التشغيل كتب. والأخت بالمعرّف `({ run: eval }).run` تسقط. المفتاح حرفي صريح داخل الأقواس، لا تخمينًا؛ طيّ مفاتيح العنصر موجود وطيّ مفتاح الخاصية المحسوبة غائب. وفي `rehydrate_proof.ts` يُطوى المفتاح المحسوب الحرفي لمواضع الإنتاج، ولا يُطوى هنا.

المتداخل: `const evil: any = ({ box: { run: eval } }).box.run; evil(…)` — EXIT=0، التشغيل كتب. أصل `.box` هو تعبير الكائن الداخلي، و`originOf` يعيده `data` فلا يُسأل العضو `run`. لفّ القيمة بمستوى واحد يعيد الأخضر. نقل للحرف الذي أُغلق في التعبير نفسه.

### RC14_METHOD_AND_CLASS_RETURN_UNSEEN

الجالب `get run()` يُسأل إرجاعه (`objectLiteralMemberOrigin` نحو 339–341). المنهج في الكائن ليس إسناد خاصية ولا جالبًا ولا نشرًا، فيُعاد `data`. `const o = { run(): any { return eval; } }; const evil: any = o.run(); evil(…)` — EXIT=0، التشغيل كتب. والصنف: `class Box { run(): any { return eval; } } new Box().run()(…)` — EXIT=0، التشغيل كتب. الدالة المحلية `function get()` تسقط (الضابط) لأن `functionReturnOrigin` يُسأل هناك. إرجاع الدالة المرئية ادُّعي جذرًا، والمنهج والصنف — وهما الدالة المرئية الأشيع — لم يُسألا. نقل لا حدّ RC-07: الجسم في الملف نفسه والنداء مرئي.

### RC14_NAMESPACE_ALIAS_AND_DESTRUCTURE_ESCAPE

`namespaceModuleOf` يشترط أن يكون الأساس معرّفًا إعلانه `NamespaceImport` (`rehydrate_origin_model.ts` نحو 204–216). `ns.escaped(…)` يسقط (ضابط gpt). الكنية تفقد الإعلان:

- `import * as ns from "./mod"` و`export const escaped: any = eval` في الوحدة، ثم `const box = ns; box.escaped(…)` — EXIT=0. التشغيل بعد الترجمة إلى CommonJS كتب `archive_snapshot`.
- `const { escaped } = ns; escaped(…)` — EXIT=0. التشغيل كتب الصنف.

أصل المعرّف `ns` نفسه `data` (ليس ImportSpecifier ولا متغيرًا)، فيضيع العضو. ربط عضو النطاق بالتصدير ادُّعي، والربط يقف عند شكل `ns.member` لا عند قيمة النطاق. نقل لعيب gpt `RC14_NAMESPACE_IMPORT_MEMBER_ESCAPE_GREENS`. الوجه الحي `node:path` عبر الكنية بقي أخضر، فالآلية لا ترفض النطاق البريء؛ هي لا ترى التنفيذ حين يُكنّى النطاق.

### RC14_IMPORT_FUNCTION_AND_DEFAULT_UNSEEN

فرع الاستيراد يتبع `getAliasedSymbol` فقط إن كان `valueDeclaration` إعلان متغير له مهيئ، وإلا يعيد `data` قبل `functionReturnOrigin` (`rehydrate_value_origin.ts` نحو 180–188). `import { evil as x }` من `export const evil = eval` يسقط (الضابط). الوجهان:

- `export function get(): any { return eval; }` ثم `import { get }` ثم `get()(…)` — EXIT=0، و`opaqueCodeReason` على `get()` وعلى النداء التالي `null`. التشغيل كتب الصنف. الدالة المحلية المكافئة تسقط.
- `export default` لقيمة `eval` ثم `import evil from …; evil(…)` — EXIT=0. الاستيراد الافتراضي ليس `ImportSpecifier`. التشغيل كتب الصنف.

متابعة الاستيراد ادُّعيت إلى «إعلان الرمز المكنّى ومهيئه». المتغير المكنّى أُغلق، والدالة المصدَّرة والتصدير الافتراضي — وقيمتاهما تنفيذ في `src/**` — بقيتا بابًا. ليس هذا حد `.d.ts`: الملفات `.ts` محلولة والجسم مرئي.

### DECLARED_INTERPROC_APPLY_BIND_SPREAD_STILL_A_DOOR

الادعاء في ترويسة الوحدة وفي r13: مواضع النداء تربط المعامل بوسيطه عبر نداء مباشر و`apply` و`bind`. الماسح لا يفعل ذلك إلا لـ`CallExpression` توقيعه المحلول ليس في ملف إعلان، والوسيط ليس نشرًا (`rehydrate_binding_flows.ts` نحو 105–113). `Function.apply` و`Function.bind` إعلانهما في `.d.ts` فيُتخطى الربط. القياس:

- `const go = (f: (code: string) => unknown, code: string): void => { f(code); }; go.apply(null, [eval, "globalThis.j.record('archive_snapshot', {})"])` — EXIT=0، التشغيل كتب. `opaqueCodeReason` على `f(code)` وعلى `go.apply(…)` أعاد `null`.
- `const b = go.bind(null, eval); b(…)` — EXIT=0، التشغيل كتب.
- `go(...[eval, "…"])` — EXIT=0، التشغيل كتب. النشر يُسقط الوسيط من الخريطة ولو كان النداء مباشرًا.

الضابط `go(eval, …)` يسقط `[RC-14]`. اختبار r13 المسمّى apply/bind هو نداء مباشر لغلاف (`viaApplyR14(eval, args)` حيث `apply` داخل الدالة على معامل رُبط بالنداء المباشر)، لا `go.apply` ولا `go.bind`. الحرف الذي سمّته الجولة التاسعة في صيغة الغلاف أُغلق، والصيغة التي يوحي بها اسم العيب والادعاء (`apply`/`bind` على الدالة نفسها) لم تُوصَل. حد «`getResolvedSignature` يتخطى `.d.ts`» يصف هذه الفجوة ولا يبرئها: المستدعى والجسم والوسيط `eval` كلها في `src/**` لا في مكتبة. العقد §4 يمنع أن يكون هذا الإعفاء بابًا. حد RC-07 المعلن (معامل لا يُرى موضع نداء لدالته) لا يغطي هذه الوجوه: موضع النداء مرئي في الملف نفسه.

### RC14_ASSIGNMENT_EXPRESSION_AND_YIELD_LOSE_ORIGIN

`originOf` على الإسناد الثنائي يعيد `data` إلا `&&` و`||` و`??` (نحو 121–127). قيمة تعبير الإسناد في اللغة هي الطرف الأيمن. `let slot: any = null; const evil: any = (slot = eval); evil(…)` — EXIT=0، التشغيل كتب. الإسناد إلى `slot` يُمسك كتدفق على `slot`، لكن المستهلك هو قيمة التعبير لا قراءة لاحقة لـ`slot`، فلا يُسأل. و`function* gen(): Generator<any> { yield eval; } gen().next().value(…)` — EXIT=0، التشغيل كتب. `collectReturns` يجمع `return` لا `yield`. إرجاع الدالة المرئية ادُّعي، والتوليد قناة إرجاع مرئية لم تُجمع.

## 5) الحدود المعلنة بمعيار §4

- إبقاء C-08 وC-21 والفجوات 7 والإكمال 97%: حد صادق، خارج نطاق البند نصًا، والأرقام ما زالت كذلك على الشجرة (`check:criteria` و`check:declaration` و`COMPLETION_CRITERIA.md`). لا أرفض به.
- المعامل الذي لا يُرى موضع نداء لدالته: حد صادق إن غاب النداء من البرنامج. لم أعلّق الرفض على دالة بلا موضع نداء. كل منتج رفضت به له نداء مرئي في `src/**`.
- تخطي `.d.ts` في `getResolvedSignature`: لا يغطّي `go.apply`/`go.bind`/`go(...)` في ملف `.ts` من البرنامج، ولا استيراد دالة `.ts` جسمها `return eval`. قبول هذا الغطاء يجعل الإعفاء بابًا، وهو ممنوع في §4 («الإعفاء يُراجَع آليًا لا يُصدَّق»). إعلان المعالجة نفسها أن الجنس لا يُغلق («الحرف يُغلق والجنس يعود») إقرار بالنقل لا إعفاء منه. الجولة طُلب منها أن تحكم على هذا النقل لا أن تصدّق الإعلان.

## 6) جواب السؤال المركزي

العيوب الستة لم تُعالج من الجذر. أُغلق حرفها: r13 عندي 2/2، وضوابطي على الحروف نفسها سقطت `[RC-14]`، والوجوه الحية التي أعدتها لم تُرفض كذبًا، والشجرة الحية و`npm test` 2497/2497 و`npm run verify` EXIT=0. الجنس واحد — قيمة `eval`/`Function` تصل إلى نداء ينفّذ نصًا يكتب `archive_snapshot` والحاجز يبقى أخضر — وعاد في صيغ لا يطأها العرّاف: فهرس مصفوفة محمولة في متغير و`.at`/`.map`، تفكيك وfor-of من ربط لا من حرفيّ، مفتاح محسوب وتداخل حرفيّ، منهج وصنف، كنية نطاق وتفكيكه، استيراد دالة وتصدير افتراضي، `apply`/`bind`/نشر على معامل معلن النوع، قيمة تعبير الإسناد و`yield`. هذا هو الجذر الذي سمّته الجولات قائمة أشكال لا برهان غياب. عدد الاختبارات وأخضر verify لا يردّانه: الاختبار يعيد الحرف، والمسبار يطلب الصيغة التي لم تُسمَّ.
