## 5. مسبار العيوب العدائي التحقيقي (Adversarial Probing)

انطلاقًا من مبدأ "الادعاء ليس دليلًا، والتنفيذ ليس إثباتًا":

### العيب الأول: `DOC_LINK_GUARD_CRLF_DESTINATION_BYPASS` (عيب مقاس في صلب نطاق البند)

#### 1. الموضع والتوصيف
في ملف حارس الروابط `tests/governance/doc_links.test.ts`، وتحديدًا في دالة مسح الوجهة المباشرة `scanInlineDestination(text: string, start: number)`:
السطر 76 ينص على:
```typescript
let i = start;
while (i < text.length && /[ \t\n]/.test(text[i]!)) i += 1;
```
النمط المستعمل لتخطي الفراغات والأسطر الجديدة هو `/[ \t\n]/`.
هذا التعبير المنتظم **أغفل تمامًا محرف الإرجاع السطري** `\r` (Carriage Return · ASCII 13 · U+000D) الشائع في نهايات أسطر Windows (CRLF: `\r\n`).

#### 2. آلية الانكسار والعمى (Bypass Mechanism)
عند وجود رابط مباشر كُتبت وجهته بعد كسر سطر بنهاية CRLF (مثال: `[link](\r\nmissing.md)` أو `[link](\r\n<missing.md>)`):
1. المؤشر `i` يبدأ بعد `](`.
2. حلقة التخطي تصل إلى محرف `\r`. وحيث إن `\r` ليس مسافة ولا علامة جدولة ولا `\n`، تتوقف الحلقة فورًا عند `\r`.
3. يفحص الكود `text[i] === '<'`. وحيث إن المحرف هو `\r`، ينتقل إلى فرع الوجهة العارية (Bare Destination).
4. في فرع الوجهة العارية (السطر 94):
   ```typescript
   if (c.charCodeAt(0) <= 0x20 || c.charCodeAt(0) === 0x7f) break;
   ```
   محرف `\r` رمزه 13 (0x0D)، وهو أصغر من 0x20، فينكسر التكرار فورًا عند `j = i`.
5. تصبح الوجهة المستخرجة `dest` فارغة (`""`)!
6. ينتقل الفحص إلى `TITLE_TAIL.test(text)`، فيفشل التعبير المنتظم لأن ما تبقى هو المسار الفعلي غير الموضوع بين علامتي اقتباس.
7. تُرجع الدالة `null`، متوهمةً أن النص ليس رابطًا في Markdown!
8. تُسقط دالة `brokenLinksIn` الرابط بالكامل، وتُرجع مصفوفة فارغة `[]`!

#### 3. معيار CommonMark 0.31.2
تنص الفقرة §2.1 (Characters and lines) والفقرة §6.5 (Inline links) من مواصفة CommonMark القياسية صراحة على:
- "A whitespace character is a space (U+0020), tab (U+0009), newline (U+000A), line tabulation (U+000B), form feed (U+000C), or carriage return (U+000D)."
- "A line ending is a newline (U+000A), a carriage return (U+000D) not followed by a newline, or a carriage return and a following newline."
وبناءً عليه، فإن عارض GitHub ومحللات CommonMark تعرض النص `[test](\r\nmissing.md)` كرابط تشعبي نشط تمامًا نحو `missing.md`.

#### 4. القياس والإثبات الحرفي بالرمز
تم تنفيذ المسبار الحرفي التالي عبر Node.js ضد شفرة المستودع المبنية:
```javascript

// مسبار CRLF للوجهة العارية والزاوية:

// النتيجة المقاسة: []  <-- عمى تام وإفلات للرابط المكسور!

// النتيجة المقاسة: []  <-- عمى تام وإفلات للرابط المكسور!

// المقارنة مع LF الخالص لنفس الروابط:

// النتيجة المقاسة: [ 'missing.md' ]  <-- يُكشف

// النتيجة المقاسة: [ 'missing.md' ]  <-- يُكشف
```
