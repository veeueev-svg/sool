- **طبيعة العيب:** بوابة التاج بطبيعتها متماثلة القوى (idempotent) بحيث تعيد `allowed=true` عند تلقي أمر معتمد سابقًا، فكانت الدالة `amendRate` تعتبر ذلك اعتمادًا جديدًا وتكرر التعديل مرة ثانية.

  2. قبل استدعاء البوابة، يُفحص معرّف الأمر:
     ```typescript

       return refuse('الأمر نُفّذ سابقًا — إعادتُه لا تُعدّل ثانيةً', { commandId: command.payload.commandId });
     ```
