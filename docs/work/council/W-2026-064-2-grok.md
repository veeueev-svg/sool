## 4) عيبُ الجلسة 1 `DOC_LINK_GUARD_ASCII_BYPASS` — أُغلق شكلُه القديم وبقي الجذر

الكودُ القديم كان يتخطّى الرابط إن خلا من حرفٍ لاتينيّ أو حوى `'`. الكودُ عند هذه الالتزامة (`tests/governance/doc_links.test.ts` · `brokenLinksIn`) أزال ذلك التخطّي. مسبارٌ استورد الدالّة من `dist/tests/governance/doc_links.test.js` و`exists = () => false`:

| النص | قاسه الحارس؟ |
|---|---|
| `[x](وثيقة.md)` | نعم → `وثيقة.md` |
| `[y](./١٢)` | نعم |
| `[q](it's.md)` | نعم → `it's.md` |
| `[x](<it's.md>)` | نعم |

اختبارُ الحارس المسمّى بالعيب يمرّ. الاستثناءُ الصريح لحرف ASCII ولعلامة `'` داخل الوجهة زال. هذا نصفُ العلاج.

الجذرُ المطلوب في هذه الجلسة: الحارس يقيس **كلَّ** رابطٍ نسبيّ بلا استثناء ASCII أو `'`. تعليقُ الدالّة يقول إنّ المخرجَ الوحيد مخطّطُ URI أو مرساةٌ خالصة. النمط:

```
/\]\(<?([^)\s>]*)>?(?:\s+"[^"]*")?\)/g
```

لا يطابق روابطَ نسبيّةً يعرضها GitHub (CommonMark)، فيسكت عنها — لا يقيسها ولا يُبلغ أنّها مكسورة:

```
node مسبار على brokenLinksIn('docs/a.md', text, () => false)
```

| النص (رابطٌ نسبيٌّ مكسور) | الناتج |
|---|---|
| `[x](missing.md 'عنوان')` | `[]` — لم يُقَس |
| `[x](missing.md (عنوان))` | `[]` — لم يُقَس |
| `[x](<my file.md>)` | `[]` — لم يُقَس |
| `[x](../../../../../../etc/passwd 't')` | `[]` — العنوانُ المفرد يخفي حتى مسارَ الصعود |
| `[x](missing.md "عنوان")` | يُقاس (العنوانُ المزدوج فقط) |
| `[x](../../../../../../etc/passwd)` بلا عنوان | يُقاس ويُبلَغ مكسورًا |

علامةُ `'` التي سمّاها العيب ما زالت تخفي رابطًا نسبيًّا إذا جاءت عنوانًا لا حرفًا داخل الوجهة. الوجهةُ ذات الفراغ داخل `<>` — وهي الصيغةُ التي يعرضها GitHub لمسارٍ فيه فراغ — لا تُقاس لأنّ الفئة `[^)\s>]*` تقف عند الفراغ فيفشل النمطُ كلُّه ولا يبقى مخرجٌ يُبلغ. ادّعاءُ «المخرجُ الوحيد المخطّطُ والمرساة» كاذبٌ على هذه الأشكال: هي لا تُخرَج ولا تُدخَل.

الشجرةُ اليوم لا تحتوي هذه الأشكال، فاختبارُ «كلُّ رابطٍ يصل» يمرّ على ما هو مكتوب لا على ما يستطيع الحارسُ أن يراه. حارسٌ يُسقط الرابطَ المكسورَ الجديد لا يكون حارسًا إذا صيغةٌ قياسيّةٌ واحدة تُعميه. هذا بقاءُ العيب من الجذر لا ملاحظةٌ شكليّة.
