## 6) مسباراتٌ مستقلة — ما اخضرَّ وهو ميّت، وما رُفض وهو حيّ

عقدُ التشغيلِ المنفصل (نداءٌ يَعُدّ نفسَه):

```
{"falseAnd":{"calls":0},"zeroAnd":{"calls":0},"unaryMinusAnd":{"calls":0},"unaryPlusAnd":{"calls":0},"bigintAnd":{"calls":0},"falseQQ":{"calls":0},"stringQQ":{"calls":0},"zeroQQ":{"calls":0},"emptyQQ":{"calls":0},"nullQQ":{"calls":1},"undefinedQQ":{"calls":1},"voidQQTrue":{"value":true},"falseQQTrue":{"value":false},"commaFalse":{"value":false},"commaJournal":{"value":1}}
```

`false ?? call()` لا ينادي. `null ?? call()` ينادي. `void 0 ?? true` قيمتُه `true`. `(0, 1)` قيمتُه `1`. `-0 && call()` و`0n && call()` لا يناديان.

إخراجُ `ts.transpileModule` لـ`false satisfies boolean`:

```
if (journal)
    (false && assertRehydrateCensus(scope));
```

`satisfies` يُمحى. الحاجزُ يقرأ المصدرَ لا الخرج. فما يخضِرّه المصدرُ يبلغ الدمجَ ويُنفَّذ كـ`false &&` الذي يسقطه الحاجزُ لو كُتب حرفًا.

## 7) العيوبُ المسمّاة

كلُّها قيست في §6. الشجرةُ غيرُ المطفَّرةِ خضراء، وذلك متوقَّعٌ ولا يغلقها. العيوبُ العشرةُ السابقةُ مغلقةٌ ولا تُعاد هنا.

1. **RC07_QQ_NONNULLISH_SHORT_CIRCUIT_SKIPS_CENSUS** — خرقُ بندِ §4 الثاني. `if (journal) (false ?? assertRehydrateCensus(...))` و`'x' ??` و`0 ??` و`'' ??` تُخرج الحاجزَ `0` وتطبع أنّ السيادةَ مقيسةٌ على `{journal}` لنداءاتِ الإرجاعِ الأربعة. الضابطُ `false &&` يخرج `1` `[RC-07]`. `null ??` و`undefined ??` يخرجان `0` وهذا صحيحٌ لأنّ اليمينَ يُنفَّذ (`calls: 1`). الإقلاعُ بعد حذفِ دعوى `tax_levy`: الضابطُ يرمي `PERSISTENCE_REHYDRATE_KIND_UNCLAIMED` قبل `REACHED_REHYDRATION`، و`false ??` و`'x' ??` يبلغان المدخلَ ويُقلعان `records=35` بلا رمز. السببُ: `guardsOf` (الأسطر 237–245) يقطع قصرَ `&&` و`||` ولا يقطع `??` حين يكون اليسارُ ثابتًا غيرَ معدوم.

2. **RC07_UNARY_ZERO_AND_SKIPS_CENSUS** — `-0 && census()` و`+0 && census()` خروجٌ `0`. الضابطُ `0 &&` خروجٌ `1`. الإقلاعُ بـ`-0 &&` : `REACHED_REHYDRATION` و`records=35` بلا رمز. `definitelyFalsy` يرى حرفيَّ `0` ولا يرى بادئةً غيرَ `!` (الأسطر 77–80). `-0` و`+0` كاذبانِ وقتَ التشغيل (`calls: 0`).

3. **RC07_BIGINT_ZERO_AND_SKIPS_CENSUS** — `0n && census()` خروجٌ `0`. الإقلاعُ: `REACHED_REHYDRATION` و`records=35` بلا رمز. لا فرعَ لحرفيِّ `BigInt` في `definitelyFalsy`. `0n && call()` ينادي 0 مرّة.

4. **RC07_SATISFIES_FALSY_AND_SKIPS_CENSUS** — `(false satisfies boolean) && census()` و`(0, false satisfies boolean) && census()` خروجٌ `0`. `strip` لا يفكّ `satisfies` و`unwrap` في `rehydrate_proof.ts` يفكّه. `ts.transpileModule` يمحو الغلافَ إلى `false &&`، وتلك الصيغةُ يخرج حاجزُها `1` لو كُتبت حرفًا. المصدرُ الذي يخضِرّه الدمجُ يُنفَّذ قصرًا. إقلاعُ الرمزِ المُترجَمِ `false &&` مضى بـ35. لم يُقلع رمزُ `satisfies` نفسُه.

5. **RC03_QQ_DEAD_EFFECT_GREENS** — جسمُ `tax_levy` الوحيد `false ?? (state.levySequence += 1)` أو `'x' ?? (+= 1)` خروجٌ `0`. الضابطُ `false && (+= 1)` خروجٌ `1` `[RC-03]`. `effectfulExpression` (الأسطر 176–178) يحسب طرفَي `??` أثرًا معًا. التشغيل: الطرفُ الأيمنُ لا يُنفَّذ. صنفٌ مُدَّعًى بلا أثرٍ مُبلَغ.
