## 4. التحقق من علاج عيوب الجلسة الأولى من الجذر

### أ. علاج عيب `DOC_LINK_GUARD_ASCII_BYPASS` (سجّله عضو gpt)
- **طبيعة العيب:** كان الحارس القديم يتجاوز أي رابط نسبي لا يحتوي حرفًا لاتينيًا (`!/[A-Za-z]/.test(link)`) أو يحتوي علامة اقتباس مفردة (`link.includes("'")`)، مما شكّل ثغرة تسمح بتمرير روابط مكسورة باللغة العربية أو بأسماء تحوي اقتباسًا.
- **العلاج الجذري:**
  1. أُعيدت كتابة منطق الاستخراج في `brokenLinksIn`:
     - نزع كتل الشفرة (المسوّرة والمضمنة) عبر `stripCode` قبل البحث.
     - استخراج الروابط بالصيغة القياسية لـ Markdown: `\]\(<?([^)\s>]*)>?(?:\s+"[^"]*")?\)`.
     - عزل وفصل المرساة (`raw.split('#')[0]`).
     - تجاهل المخططات الخارجية فقط `^[a-z][a-z0-9+.-]*:`.
     - فك ترميز النسبة المئوية للروابط المشفرة (`decodeURIComponent`).
     - احتساب المسار النسبي انطلاقًا من مجلد الملف الأصلي.
  2. شُغّل مسبار اختبار عدائي:
     ```javascript
     const { brokenLinksIn } = require("./dist/tests/governance/doc_links.test.js");
     brokenLinksIn("docs/a.md", "[test](ملف_غير_موجود.md)", () => false); // يلتقطه فورًا: ['ملف_غير_موجود.md']
     brokenLinksIn("docs/a.md", "[test](don't_exist.md)", () => false);   // يلتقطه فورًا: ["don't_exist.md"]
     ```
     تم القضاء على التجاوز اللاتيني وتجاوز الاقتباس نهائيًا وبشكل مثبت.

### ب. علاج عيب ترويسة `ARCHITECTURE.md` (سجّله عضو grok)
