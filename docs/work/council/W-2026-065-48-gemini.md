## 3. فحص علاج عيبَي الجولة 47 وقتل الطفرات

### أ) تقييم علاج عيب gpt: `TAX_WAIVE_COMMAND_ISSUED_AT_MUTABLE_EXPIRY_BYPASS`
- **التوصيف:** كان مسار الإعفاء `waive()` يستدعي `royalCommandWitness(command, false)`، مما جعل حارس البدائية لـ `issuedAt` معطلاً في هذا المسار لأن التحقق كان محصورًا بشرط `withIssuedAt`. وكان ذلك يسمح بتمرير كائن `Date` قديم كطابع زمني يُوقّع كـ `{}` ثم يُحرّك عبر `setTime()` ليتجاوز فحص العمر في البوابة ويُحدث إعفاءً دائمًا ينجو عبر الإقلاع.
- **التحقق من العلاج:** في التجميد `d33ad70ec710595faa4d4085b23c3c2592ab1399` في `src/economy/tax_types.ts`، تم استئصال شرط `withIssuedAt` من فحص `issuedAt`. أصبح الحارس:
  ```ts
  if (typeof issuedAt !== 'number' || !Number.isFinite(issuedAt)) {
    return { ok: false, reason: 'لحظةُ إصدارِ الأمرِ رقمٌ محددٌ لا كائنٌ يُكرَه عند حسابِ العمر — وذاك مرجعٌ حيٌّ يُدوَّنُ في السجلِّ فيكسرُه' };
  }
  ```
  يعمل على **كافة** الاستدعاءات (`waive` و`amendRate` معًا بلا استثناء). ويتم أخذ لقطة سطحية مقروءة بدائية لـ `issuedAt`.
- **النتيجة:** العلاج حقيقي وجذري؛ تمرير كائن `Date` أو أي قيمة غير عددية يُرفض فورًا قبل البوابة وقبل أي تدوين.

### ب) تقييم علاج عيب grok: `RATE_AMENDMENT_APPROVAL_BINDING_OMITS_ISSUED_AT`
- **التوصيف:** كان `authorizeBound` يكتفي بمطابقة أربعة حقول (`commandId` و`action` و`target` و`params`) متجاهلاً `issuedAt` و`issuedBy`. وكانت بوابة التاج تُعيد القرار المعتمد السابق لأي حمولة تحمل `commandId` سبق اعتماده دون فحص التوقيع. فكان المهاجم قادرًا على تقديم أمر غير موقّع بمعرّف معتمد مع `issuedAt=1` و`issuedBy` مزوّر فيتم قبول التعديل ويُسجّل شاهد زائف ويدوم عبر الإقلاع.
- **التحقق من العلاج:** في `src/economy/tax_types.ts`، تم توسيع شروط الربط في `authorizeBound`:
  ```ts
  const ageMs = now - (p.issuedAt as number);
  const bound = hit !== null && d !== null
    && d['commandId'] === p.commandId && d['action'] === p.action && d['target'] === p.target
    && canonicalJson(d['params'] ?? null) === canonicalJson(p.params ?? null)
    && hit.actor === p.issuedBy
    && typeof p.issuedAt === 'number' && Number.isFinite(p.issuedAt)
    && ageMs <= GATEWAY_MAX_COMMAND_AGE_MS && ageMs >= -GATEWAY_FUTURE_TOLERANCE_MS;
  ```
  حيث:
  1. `hit.actor === p.issuedBy`: يربط الأمر بالفاعل المعتمد نفسه (الملك المسجل) ولا يقبل مُصدِرًا مزوّرًا.
  2. `typeof p.issuedAt === 'number' && Number.isFinite(p.issuedAt)`: يحرس بدائية لحظة الإصدار.
  3. `ageMs <= 120_000 && ageMs >= -5_000`: يُلزم لحظة الإصدار بالبقاء داخل نافذة العمر الرسمية للبوابة (بين 5 ثوانٍ في المستقبل و120 ثانية في الماضي).
- **النتيجة:** العلاج حقيقي وفعّال داخل نطاق البند.

### ج) قتل الطفرات في نسخ معزولة (المقيس بالأرقام)
أنشأتُ 3 نسخ معزولة من الشجرة وطبقتُ على كلٍّ منها طفرة مستقلة، وأعدتُ البناء والتشغيل:
