### 4.2 العيب الجذري الفاضح: نفي المنتج المعتم لا يزال قائمة حظر شكلية مخترقة (`RC14_*`)

فحصتُ دالة `opaqueCodeReason` في `scripts/rehydrate_opaque_code.ts`، والتي زُعم أنها تقيس أبواب الشفرة المعتمة "بآلياتها لا بأسمائها".
الكود الفعلي المضاف في المعالجة العاشرة:
```typescript
if (ts.isCallExpression(n) && ts.isPropertyAccessExpression(n.expression)
  && ts.isIdentifier(n.expression.expression)) {
  const obj = n.expression.expression.text;
  const prop = n.expression.name.text;
  if (obj === 'Reflect' && prop === 'get') {
    return 'انعكاسُ وصولٍ Reflect.get — يبلغُ أيَّ خاصّيّةٍ ومنها منشئَ الدالّةِ ولا يُقرأُ ساكنًا';
  }
  if (obj === 'Object' && prop === 'getOwnPropertyDescriptor') {
    return 'واصفُ خاصّيّةٍ Object.getOwnPropertyDescriptor — القيمةُ تُبلَغُ ديناميكيًّا فلا يُبرهَنُ غيابُ منشئِ الدالّةِ';
  }
}
```
**العوار البنيوي الصارخ:**
1. الكود يقارن حرفيًا اسم المعرّف المباشر `obj === 'Reflect'` و `obj === 'Object'`.
2. لم يُضف كائن `Reflect` ولا `Object` إلى مجموعة `GLOBAL_OBJECTS`.
3. لم تُستدعَ دالة تتبع الأسماء المستعارة `isGlobalObjectOrAlias` على كائن `Reflect` أو `Object` قط!
4. الكود يفترض حصرًا أن الوصول يتم عبر `ts.isPropertyAccessExpression`، متجاهلًا تمامًا الوصول الفهرسي بالأقواس `ts.isElementAccessExpression`!
5. دالة `isGlobalObjectOrAlias` تعيد `false` فورًا إذا كان التعبير ليس `Identifier`، مما يجعل أي سلسلة وصول مثل `globalThis.globalThis` تفلت من الرصد تمامًا!

2. **مخالفة القاعدة الحاكمة الدستورية RULE-001:**
   القاعدة الدستورية الأولى للنظام تنص على:
   > **«المجهولُ لا يؤيّدُ الإعفاءَ ولا السيادة»**
   عندما يعجز الحاجز الساكن عن البرهنة على سلامة الوصول المعجمي أو الانعكاسي، فالأصل بموجب RULE-001 هو رفض الإعفاء (`[RC-14] غياب المنتج لا يبرهن`)، لا السماح به افتراضًا وادعاء أن العجز هو "حد معلن يُرفع للمالك"!
3. **لعبة «مطاردة الصيغ» (Whack-a-Mole Anti-Pattern):**
   ما فعله المنفّذ في المعالجات المتعاقبة (من الجولة 1 حتى الجولة 7) هو توسيع رقعة القائمة السوداء بعد كل جولة يرفض فيها المجلس عمله: يكتشف المراجع ثغرة فيضيف المنفّذ اسم الخاصية حرفيًا، فإذا استعار المراجع الاسم فلتت الشفرة مرة أخرى! هذا النمط لا يمثل برهانًا رياضيًا أو هندسيًا على غياب المنتج، بل هو غطاء شكلي زائف يخلق شعورًا كاذبًا بالأمان.
4. **أثر الاختراق في سلامة النظام:**
   صنف `archive_snapshot` معفى من وجود مستهلك إرجاع في `src/data/persistence.ts`. إذا تم تدوين هذا القيد في اليومية عبر أي من الثغرات الخمس المذكورة، فإن النظام سينهار فورًا عند أول إعادة إقلاع لأن حارس التشغيل (`assertExemptionsHold`) سيرمي استثناء سياديًا غير معالج (`PERSISTENCE_REHYDRATE_EXEMPTION_CONTRADICTED`)، مما ينسف استمرارية الدولة الرقمية.

لذا، فإن محاولة التهرب من معيار القبول بتسميته "سياسة حاجز للمالك" هي التفاف باطل لا يلزم المجلس، ومعيار القبول ساقط هندسيًا وتعاقديًا.
