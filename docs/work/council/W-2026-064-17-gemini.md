## 2. فحصُ شفرة `stripCode` الجديدة

تم فحص الشفرة في `tests/governance/doc_links.test.ts` عند الالتزام المجمّد `98a7bb8` ومقارنتها بالشفرة السابقة عند `e88d74a`:

### الشفرة السابقة (المعيبة عند `e88d74a`):
```typescript
export function stripCode(text: string): string {
  return text.replace(/^(```|~~~)[^\n]*\n[\s\S]*?^\1[^\n]*$/gm, '').replace(/(`+)[^`\n]*?\1/g, '');
}
```
كانت تستعمل التعبير النمطي العالمي `/(`+)[^`\n]*?\1/g` الذي يحذف كل ما بين أول علامتي backtick متماثلتين في الطول دون النظر إلى ما إذا كانت العلامة الأولى مهرّبة بشرطة مائلة عكسية (`\``).

### الشفرة الجديدة (المعالجة عند `98a7bb8`):
```typescript
/**
 * ماسحُ الشفرةِ المضمّنةِ (الجلسة 16 · CommonMark 0.31.2 §6.1): سطرًا سطرًا. خارجَ الشفرةِ `\\`
 * تأكلُ ما بعدها — فالعلامةُ المهرَّبةُ لا delimiterٌ؛ وداخلَها لا تُعالَجُ الشرطةُ.
 */
export function removeInlineCode(text: string): string {
  return text.split('\n').map(removeInlineCodeLine).join('\n');
}
function removeInlineCodeLine(line: string): string {
  let out = '';
  let i = 0;
  while (i < line.length) {
    if (line[i] === '\\') { out += line.slice(i, i + 2); i += 2; continue; } // تهريب
    if (line[i] === '`') {
      let j = i; while (line[j] === '`') j++;
      const run = line.slice(i, j);
      let k = j, close = -1;
      while (k < line.length) {
        if (line[k] === '`') {
          let m = k; while (line[m] === '`') m++;
          if (m - k === run.length) { close = k; k = m; break; }
          k = m;
        } else k++;
      }
      if (close >= 0) { i = k; continue; } // الشفرةُ تُسقَطُ
      out += run; i = j; continue; // بلا مقابلٍ ⇒ حرفيّةٌ
    }
    out += line[i]; i++;
  }
  return out;
}

export function stripCode(text: string): string {
  return removeInlineCode(text.replace(/^(```|~~~)[^\n]*\n[\s\S]*?^\1[^\n]*$/gm, ''));
}
```

### التحقق البنيوي:
1. **استعمال الماسح السياقي:** دالة `stripCode` استبدلت النمط القديم بمناداة `removeInlineCode` بعد نزع الكتل المسوّرة (`fenced code blocks`).
2. **المعالجة بالسياق لا بالاستبدال الأعمى:**
   - خارج الشفرة: محرف الهروب `\` يأكل المحرف الذي يليه مباشرة (`out += line.slice(i, i + 2); i += 2;`)، فإذا تلاه backtick اعتُبر حرفًا نصيًّا مجردًا ودُفع إلى المخرج، ولم يُعامل كفتاحة شفرة (`delimiter`).
   - داخل الشفرة: يتم البحث عن علامة إغلاق مطابقة للطول (`m - k === run.length`) دون معالجة الشرطة المائلة العكسية، وهو ما يتطابق حرفيًّا مع مواصفة **CommonMark 0.31.2 §6.1** (*«Backslash escapes do not work in code spans»*).
   - الشفرة غير المغلقة على السطر: تُعامل علامة الفتح كحرف مجرد وتُحفظ في المخرج دون ابتلاع ما بعدها.

يحتوي الاختبار الخامس على 8 تأكيدات حاسمة تغطي كافة الجوانب:
1. `brokenLinksIn('docs/a.md', 'See \\` [x](missing.md) ` end', none)` ⇒ `['missing.md']` (مسبار الجلسة 16).
2. `brokenLinksIn('docs/a.md', 'a`[x](m.md)` b \\` [y](n.md) ` c', none)` ⇒ `['n.md']` (شفرة سليمة متبوعة بـ backtick مهرّب ورابط مكسور).

5. `brokenLinksIn('docs/a.md', 'text \\\\\\` [l5](u5.md) and `span` [l6](u6.md)', none)` ⇒ `['u5.md', 'u6.md']` (ثلاث شرطات: تهريب الـ backtick وشفرة سليمة ورابطان).
6. `brokenLinksIn('docs/a.md', '``code with ` inside`` [l4](u4.md)', none)` ⇒ `['u4.md']` (علامة فردية داخل شفرة ثنائية لا تفتح ولا تغلق).
7. `brokenLinksIn('docs/a.md', 'See \\\\` [x](missing.md) ` end', none)` ⇒ `[]` (سالبة الضبط: شرطتان مائلتان تعنيان أن الـ backtick عارٍ ويفتح شفرة حقيقية تُغلق لاحقًا، والرابط داخلها نصٌّ لا رابط).
8. `brokenLinksIn('docs/a.md', '`code \\` [x](missing.md) ` end', none)` ⇒ `['missing.md']` (الشرطة المائلة داخل الشفرة لا تهرب الـ backtick، فالـ backtick يغلق الشفرة والرابط يقع خارجها فيُقاس).

**الخلاصة:** عيب الجلسة 16 عولج علاجًا جذريًّا محكمًا ومثبّتًا باختبارات انحدار شاملة ومقيسة.

## 4. فحصٌ خصوميّ إضافي: هل يوجد مسلكٌ جديدٌ في `removeInlineCode` يعود الرابطُ فيه صامتًا؟

### المسابير العدائية المختبرة مقابل CommonMark / GFM:

1. **التهريب الفردي والزوجي الممتد:**
   - `See \` [x](missing.md) ` end` ⇒ GFM يعرض الرابط · الحارس يعيد `['missing.md']` (تطابق).
   - `See \\` [x](missing.md) ` end` ⇒ GFM يبتلع الرابط كشفرة مضمنة · الحارس يعيد `[]` (تطابق).
   - `See \\\` [x](missing.md) ` end` ⇒ GFM يعرض الرابط · الحارس يعيد `['missing.md']` (تطابق).
   - `See \\\\` [x](missing.md) ` end` ⇒ GFM يبتلع الرابط كشفرة مضمنة · الحارس يعيد `[]` (تطابق).

2. **الـ backtick المهرّب المتصل بالرابط مباشرة:**
   - `\`[x](missing.md)` ⇒ الرابط يعرضه GFM · الحارس يعيد `['missing.md']` (تطابق).
   - `\`\`[x](missing.md)` ⇒ الرابط يعرضه GFM · الحارس يعيد `['missing.md']` (تطابق).
   - `\\[x](missing.md)` ⇒ شرطة مهرّبة تليها رابط · الحارس يعيد `['missing.md']` (تطابق).

3. **شفرة مضمنة داخل نص الرابط (Link Text):**
   - `[`code`](missing.md)` ⇒ GFM يعرض `<a href="missing.md"><code>code</code></a>` · الدالة تجرد الشفرة لتصبح `[](missing.md)` فيلتقطها ماسح الوجهات ويعيد `['missing.md']` (تطابق تام وبلا عمى صامت).
   - `[foo `bar` baz](missing.md)` ⇒ الحارس يعيد `['missing.md']` (تطابق).
   - `[`foo \` bar`](missing.md)` ⇒ الحارس يعيد `['missing.md']` (تطابق).

4. **تعدد أطوال العلامات (Backtick Run Matching):**
   - ```` `` ` [x](missing.md) `` ```` ⇒ علامة فتح ثنائية، داخلها علامة أحادية نصية، ثم إغلاق ثنائي. الرابط بداخلها شفرة نصية · الحارس يعيد `[]` (تطابق).
   - ```` ` unclosed `` [x](missing.md) `` ```` ⇒ علامة فتح أحادية بلا إغلاق، ثم علامة ثنائية تفتح شفرة تحوي الرابط وتغلقها · الحارس يعيد `[]` (تطابق).
   - ```` ``code with ` inside`` [l4](missing.md) ```` ⇒ شفرة مغلقة يليها رابط خارجي · الحارس يعيد `['missing.md']` (تطابق).

5. **تداخل الكتل المسوّرة مع العلامات المهرّبة:**
   - `\` ```\n[x](nope.md)\n``` [y](missing.md)` ⇒ الكتلة المسوّرة تُنزع أولًا، ثم الرابط الخارجي يُلتقط · الحارس يعيد `['missing.md']`.
