## 5) العيوب المسماة

الجنس واحد: قيمة تنفيذ (`eval` / `Function`) تصل إلى نداء ينفّذ نصًا يكتب `archive_snapshot`، والحاجز يبقى أخضر. الحرف المغلق هو «المهيئ هو `eval` نفسه» أو «الأساس معرّف مهيؤه كائن حرفي». ما دون ذلك باب.

### RC14_INLINE_LITERAL_EXTRACTION_GREENS

نقلٌ لـ`RC14_ANY_CALL_NO_JOURNAL_ARG_GREENS` و`RC14_TYPE_LAUNDERING_GREENS`، لا حدًّا معلنًا. المسح يسجّل المهيئ، لكن `originOf` على وصول خاصية أو فهرس أساسه حرفيّ (لا معرّف) يعيد `data` دون النزول إلى العضو (`literalRootOf` يشترط معرّفًا مهيؤه كائن حرفي — `rehydrate_value_origin.ts:315–321` و`:292`).

- `const evil: any = ({ run: eval }).run; evil("globalThis.j.record('archive_snapshot', {})")` — الحاجز خروج 0، لا `[RC-14]`. التشغيل كتب `archive_snapshot`. التشخيص النوعي 0.
- `const evil: any = [eval][0]; evil(…)` — خروج 0. التشغيل كتب الصنف. المفتاح الرقمي لا يُطوى (`foldKey` لا يطوي إلا النص).
- `const F: any = ({ F: Function }).F; F("globalThis.j.record('archive_snapshot', {})")()` — خروج 0. التشغيل كتب الصنف. التشخيص النوعي 0.

الشاهد العكسي الذي يثبت أن الآلية ترى الصيغة المسماة فقط: `const box = { run: eval }; const evil: any = box.run; evil(…)` يسقط `[RC-14]` («مستدعًى أصله تنفيذ»). و`const evil: any = eval` يسقط. لفّ القيمة بحرفيّ في التعبير نفسه يعيد الأخضر.

`Reflect.get` المستخرَج بالطريقة نفسها يسقط، لا لأن الاستخراج تُتُبّع، بل لأن الوصول `Reflect.get` نفسه عقدة باب (المفتاح `get` على كائن الباب). الرسالة المقيسة: «وصول أصله تنفيذ ديناميكي («Reflect.get» — باب انعكاسي)». المعرّف `eval` أو `Function` داخل الحرفي ليس وصولًا، فلا يُعلَم.

### RC14_NEW_OF_FUNCTION_ALIAS_GREENS

نقلٌ لتغسيل `Function`. `originOf` على `new` يعيد تنفيذًا فقط إذا كان المستدعى بعد فك الأغلفة معرّفًا مكتبيًا اسمه `Function` (`rehydrate_value_origin.ts:189–191`). لا يسأل العرّاف عن أصل المعرّف. الباب (و) في `opaqueCodeReason` يفحص `CallExpression` لا `NewExpression`.

- `new (Function as any)("…")` يسقط، والرسالة: «new Function(…) — منشئ دالة من نص». فك `as` يبلغ المعرّف المكتبي. هذا الحرف مغلق.
- `const C: any = Function; const fn = new C("globalThis.j.record('archive_snapshot', {})"); fn();` — خروج 0. التشغيل كتب الصنف (`new C(…)()`). التشخيص النوعي 0. أصل `C` تنفيذ عند العرّاف (الإسناد يُمسَك)، والنداء بـ`new` لا يسأل العرّاف، ونوع `C` هو `any` لا `Function` فلا يمسكه الباب (أ).

### RC14_BINDING_CHANNELS_LOSE_MEMBER_ORIGIN

المسح يربط اسم التفكيك أو عنصر `for-of` بالمهيئ كله لا بالعضو (`rehydrate_value_origin.ts:129–149`)، و`originOf` على كائن حرفي أو مصفوفة يسقط إلى `data` (السطر 202). الجالب والنشر و`Object.assign` و`catch` لا تُدمَج في تدفق الخاصية. ليست هذه قنوات «معامل بين دالتين» المعلنة؛ هي ربط داخل الملف.

كلها خروج 0 على الحاجز، والتشغيل كتب `archive_snapshot` حيث أعدت القياس:

- `const { run }: { run: any } = { run: eval }; run(…)` — تشخيص نوعي 0.
- `const [run]: [any] = [eval]; run(…)`.
- `for (const run of ([eval] as any[])) run(…)`.
- `function box(): any { return eval; } box()(…)`.
- `function box(): (code: string) => unknown { return eval; } box()(…)` — الإرجاع ليس المعامل المعلن، والبوابة تخضرّه.
- جالب `get run(): any { return eval; }` ثم `o.run(…)`.
- `const o: any = { ...{ run: eval } }; o.run(…)`.
- `const o: any = Object.assign({}, { run: eval }); o.run(…)`.
- `try { throw eval; } catch (e) { const run: any = e; run(…); }`.

### RC14_IMPORT_ALIAS_VALUEDECLARATION_MISSED

الادعاء في ترويسة الوحدة والالتزام: الاستيراد يُتبَع إلى مهيئه. الفرع الذي يفعل ذلك يشترط `valueDeclaration` من نوع `ImportSpecifier` (`rehydrate_value_origin.ts:238–245`). إن غاب الإعلان سقط المسار إلى `return DATA` (السطر 247).

الوجه، والاستيراد في قمة الملف لا داخل الدالة: `src/probe_helper.ts` فيه `export const evil: any = eval`، و`src/data/persistence.ts` فيه `import { evil as probeEvil } from "../probe_helper"` ثم `probeEvil("globalThis.j.record('archive_snapshot', {})")`. الحاجز خروج 0. برنامج الأنواع على الشجرة نفسها: 0 تشخيصات. الرمز عند النداء: علم `Alias`، `valueDeclaration` غير معرّف، والرمز المكنّى `evil` إعلانه `VariableDeclaration`. العرّاف لا يرى الإعلان فلا يتبع المهيئ. الوجه نفسه داخل الملف (`const evil: any = eval`) يسقط `[RC-14]`. العبور إلى ملف آخر يعيد الأخضر. هذا كذب الآلية المدّعاة لا حدًّا مكتوبًا في §2-ع.

### DECLARED_INTERPROC_PARAM_APPLY_BIND_STILL_A_DOOR

الحدود المعلنة في §2-ع وINSTRUCTIONS §4 قيست، وهي أبواب لا دَينًا مقبولًا:

- `const go = (f: (code: string) => unknown, code: string): void => { f(code); }; go(eval, "globalThis.j.record('archive_snapshot', {})")` — خروج 0. التشخيص النوعي 0. التشغيل كتب الصنف. المعامل المعلَن النوع ليس `any`/`unknown` فـ`paramOrigin` يعيده `data` (السطر 250–254)، والتوقيع المحلول توقيع المعامل لا `eval`.
- `f.apply(null, args)` والمعامل `f: any` والمصفوفة معرّف — خروج 0. `eval.apply(globalThis, args)` نفسه يسقط لأن أصل المستدعى `eval`. الحد يعضّ حين لا يُتتبَّع المستدعى.
- `f.bind` على معامل معلن النوع ثم النداء — خروج 0. `eval.bind` المتتبَّع يسقط.

العقد §4: «الإعفاء لا يكون بابًا: صنف معفًى بحجة لا منتج له يسقط برمز مسمى إن ظهر له منتج في `src/**` — فالإعفاء يُراجَع آليًا لا يُصدَّق». هذه الدوال منتج في `src/data/persistence.ts`، و`check:rehydrate-census` يخرج 0. الحارس عند القراءة لا يراجع المصدر؛ يراجع قيدًا مكتوبًا بعد التنفيذ. الجولة الثامنة رفضت الاحتجاج بالحارس غطاءً لحدٍّ لا يقيسه الحاجز. القياس هنا يعيد الباب نفسه على معامل معلن النوع، وهو أوسع من حد `any` الذي أُغلق حرفه.
