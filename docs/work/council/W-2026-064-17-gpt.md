## الفحص الخصومي الإضافي

**عيب جديد مسمّى:** `SESSION17_INLINE_CODE_CROSSLINE_STATE_BYPASS`.

الماسح `removeInlineCode` يقسم النص عند `\n` ويستدعي
`removeInlineCodeLine` لكل سطر مستقل. لكن مواصفة CommonMark §6.1 تجعل
نهايات الأسطر جزءًا جائزًا من span الشفرة وتحوّلها إلى مسافة؛ فلا يجوز فقد
حالة delimiter عند الحد بين سطرين ([CommonMark 0.31.2 §6.1](https://spec.commonmark.org/0.31.2/#code-spans)).

هذا المسبار الحرفي قابل للإعادة:

```sh
node - <<'NODE'
const m = require('./dist/tests/governance/doc_links.test.js');
const text = '`\n` [x](missing.md) `';
console.log('stripCode:', JSON.stringify(m.stripCode(text)));
console.log('brokenLinksIn:', JSON.stringify(
  m.brokenLinksIn('docs/a.md', text, () => false)
));
NODE
```

النتيجة المعادة:

```text
stripCode: "`\n"
brokenLinksIn: []
```

في CommonMark، الـ backtick في السطر الأول يفتح code span، والـ backtick
الأول في السطر الثاني يغلقه؛ لذلك `[x](missing.md)` بعده رابط خارج الشفرة
وجب أن يعاد `["missing.md"]`. أما التنفيذ الحالي فيعامل السطر الثاني وحده،
فيقرن الـ backtick الذي أغلق span الحقيقي بالـ backtick الأخير غير المغلق،
ويمحو الرابط الصالح للفحص. النتيجة رابط مكسور صامت.
