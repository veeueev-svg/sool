## §1 ما نُفّذ — آليةُ «الحياةِ» في حارسِ نقطةِ الاختناق

**علاجُ عيبٍ واحدٍ لا ادّعاءَ إغلاقِ البقيةِ** — العيوبُ الخمسةُ الباقيةُ من عيوبِ الجولةِ الثامنةِ (RC14_CALL_APPLY_TRAMPOLINE_ESCAPE_GREENS · RC14_TYPE_LAUNDERING_GREENS · RC14_ANY_CALL_NO_JOURNAL_ARG_GREENS · RC14_FALSE_REJECTS_CONSTRUCTOR_AND_SAFE_INDEX · DECLARED_ANY_LIMIT_MISDIAGNOSED_ARRAY_ISARRAY) **باقيةٌ مفتوحةً كما هي** (تُعالَجُ في المعالجةِ الجذريةِ لتدفّقِ القيمِ — التزامٍ تالٍ).

- **`scripts/rehydrate_barrier_binding.ts`:** دالّةٌ جديدةٌ `callIsLiveInBody` — الحارسُ لا يُعَدُّ حارسًا لنقطةِ الاختناقِ إلا إذا كانَ نداؤُهُ **حيًّا في جريانِ جسمِ الدالّةِ**. المشيُّ يصعدُ من النداءِ إلى جسمِ الدالّةِ نفسِهِ وأوّلُ عِلّةٍ ميّتةٍ تُقصيه: **(أ)** دالّةٌ داخليةٌ (سهميّةٌ أو تعبيريةٌ أو تعريفٌ أو عضوُ صنفٍ) بينَ النداءِ والجسمِ — لا يُنفَّذُ النداءُ إلا بنداءِ تلكَ الدالّةِ هو لا بجريانِ الجسمِ الحاوي · **(ب)** فرعُ شرطٍ ثابتِ الكذبِ (`if (false)` ثمّ `thenStatement` · فرعُ `?:` الميّتُ · جسمُ حلقةٍ شرطُها ثابتُ الكذبِ) وفرعُ `else` بشرطٍ ثابتِ الصدقِ · **(ج)** يمينُ `&&` بيسارٍ ثابتِ الكذبِ ويمينُ `||` بيسارٍ ثابتِ الصدقِ · **(د)** نداءٌ بعدَ `return`/`throw` مباشرٍ يسبقُهُ في نفسِ الكتلةِ (الجريانُ المستقيمُ). و`chokepointGuarded` صارت تبحثُ عن حارسٍ **حيٍّ** فقط: الميّتُ يُتجاوَزُ ويستمرُّ البحثُ عن حارسٍ حيٍّ آخرَ في الجسمِ (لا يُكتفى بأوّلِ نداءٍ). الحارسُ الحيُّ القانونيُّ القائمُ في الشجرةِ (نداءٌ مباشرٌ في رأسِ الجسمِ) لا يُرفَضُ — لا رفضًا كاذبًا (وجهُ الحياةِ الحيّةِ أُضيفَ للقياسِ). **حدٌّ معلَنٌ في الآليةِ (مسجَّلٌ في تعليقِ الدالّةِ):** نهايةٌ غيرُ شرطيةٍ داخلَ كتلةٍ فرعيةٍ سابقةٍ للنداءِ في نفسِ الكتلةِ الأمِّ (`{ { return; } guard(); }`) لا تُدركُها هذهِ الآليةُ — النطاقُ عِلّةٌ واحدةٌ بينَ النداءِ والجسمِ.
- **`tests/data/rehydrate_census_mutations_r11.test.ts` (إلحاقٌ مؤرَّخٌ لا ملفٌّ جديد — لا حجزَ لملفِّ r12):** وجهانِ سالبانِ بالطفرةِ نفسِها التي قاسَها الأعضاءُ (المسابرُ مأخوذةٌ بحروفِها من خامِّ gemini): الفرعُ الميّتُ `if (false) { assertExemptionsHold(…) }` · والدالّةُ الداخليةُ غيرُ المستدعاةُ `const dummy = () => { assertExemptionsHold([]); }; void dummy;` — كلاهُما يسقطُ برمزِ RC-07. ووجهٌ حيٌّ جديدٌ للرفضِ الكاذبِ: حارسٌ تحتَ شرطٍ حيٍّ `if (entries.length > 0) { assertExemptionsHold(…) }` لا يُرفَضُ (الحياةُ لا تعني انعدامَ الشرطِ بل انعدامَ الموتِ الثابتِ).

## §6 تتمةٌ بعدَ ملاحظةِ المراجعِ (2026-10-24 · الالتزامُ التالي لـ`bf2fc1b`)

ملاحظةُ المراجعِ على المعالجةِ الأولى صحيحةٌ وقُبلت: **الحارسُ الميّتُ في كتلةٍ فرعيةٍ أختٍ (`{ { return; } guard(); }`) عيبٌ منَ الجنسِ نفسِهِ لا حدٌّ توثيقيٌّ** — عولجَ: قاعدةُ الكتلةِ الأمِّ صارت تُقصي النداءَ إذا سبقَهُ في نفسِ الكتلةِ بيانُ نهايةٍ غيرِ شرطيةٍ مباشرٌ أو كتلةٌ فرعيةٌ أختٌ تضمُّ بيانَ نهايةٍ غيرِ شرطيةٍ. **والاستدعاءُ الفوريُّ (IIFE) شفّافٌ لا رفضًا كاذبًا:** الدالّةُ الداخليةُ المستدعاةُ فورًا في موضعِها (`(() => { guard(); })();`) يُنفَّذُ جسمُها في الجريانِ نفسِهِ فلا تُقصي نداءَها — يُصعَدُ المشيُّ من موضعِ الاستدعاءِ (معَ تسلّقِ الأقواسِ والفواصلِ). ووجهانِ جديدانِ أُضيفا للقياسِ: سالبٌ (الكتلةُ الفرعيةُ الميتةُ — يسقطُ برمزِ RC-07) وحّيٌّ (الاستدعاءُ الفوريُّ — لا يُرفَضُ) معَ وجهَيِ الانحدارِ (الفرعُ الميّتُ · الدالّةُ الداخليةُ غيرُ المستدعاةِ — ما زالا يسقطانِ).

**حدٌّ معلَنٌ باقٍ (صياغةٌ مصوّبةٌ):** دالّةٌ داخليةٌ معرّفةٌ باسمٍ واستُدعيت لاحقًا (`const f = () => { guard(); }; f();`) لا تُحسَبُ حارسًا — إثباتُ تنفيذِها في الجريانِ تحليلٌ بينيٌّ خارجَ هذهِ الآليةِ (الشجرةُ الحيّةُ لا تستعملُهُ). **فالعيبُ RC07_CHOKEPOINT_DEAD_GUARD_ACCEPTED عولجَ لوجوهِهِ المقيسةِ والمكتشفةِ لا إغلاقًا لجنسِهِ كاملًا** — والمعالجةُ الجذريةُ لتدفّقِ القيمِ (العيوبُ الخمسةُ الباقيةُ) التزامٌ تالٍ كما هو.


## §7 تصويبُ الوجهِ واستثناءُ المولّداتِ (2026-10-24 · المراجعةُ الثانية للمراجعِ)

تصويبٌ بعدَ المراجعةِ الثانيةِ (بالإلحاقِ لا بمحوِ §6): **(1) وجهُ الكتلةِ الفرعيةِ صُوّب إلى صيغةِ الأختِ** `{ { return; } guard(); }` — الصيغةُ الأولى (`{ return; guard(); }`) كانت تقيسُ قاعدةَ العودةِ المباشرةِ القائمةَ قبلًا لا القاعدةَ الجديدةَ. القياسُ قبل/بعد على الوجهِ المصوّبِ: **ينجو عندَ `bf2fc1b` (EXIT=0 — العيبُ باقٍ هناكَ كما قالَ المراجعُ) ويسقطُ بعدها برمزِ RC-07**. **(2) المولّداتُ مستثناةٌ من شفافيةِ الاستدعاءِ الفوريّ:** استدعاءُ المولّدِ `(function* () { guard(); })();` يُنشئُ المُكرِّرَ ولا يُنفّذُ الجسمَ حتى الاستئنافِ — فليسَ حارسًا حيًّا ووجهٌ سالبٌ جديدٌ قيسَ يسقطُ (وعندَ `bf2fc1b` كانَ يسقطُ لسببٍ أعمّ — رفضُ كلِّ دالّةٍ داخليةٍ — فالوجهُ يثبتُ أنّ الشفافيةَ لم تتوسّعْ فوقَ دلالةِ التنفيذِ). **(3) وجهٌ معلَنٌ باقٍ ضمنَ عملِ RC-07 المفتوحِ لا خارجَه:** الدالّةُ الداخليةُ المعرّفةُ باسمٍ والمستدعاةُ لاحقًا (`const f = () => { guard(); }; f();`) — إن كانت توفرُ الحراسةَ المطلوبةَ فرفضُها رفضٌ كاذبٌ باقٍ يُدرَسُ في المعالجةِ الجذريةِ (تحليلٌ بينيٌّ) ولا يُختزَلُ إلى «خارجِ الآليةِ».
