## §1 — العلّة المقيسة

في `scripts/audit/probes_institutions.mjs` السطر 147 كان:

```javascript
const N = 1000000; // السقف السكاني المعلن في config/scale.yaml
```

التعليق يدّعي أنّ القيمة هي «السقف السكاني المعلن في config/scale.yaml»، ولكنّها مُثبَّتة لا مقروءة. والتهيئة حُدّثت إلى `population_max: 3000000` بقرار المالك في W-2026-059. فالمسبار يقيس عند مليون بينما يعلن المستودع ثلاثة.

مراجع C-17 (W-2026-059) سجّل هذا عينَه: `OFFICIAL_PROBE_STILL_MEASURES_ONE_MILLION`.

### علّة موثّقة لا تُصلح هنا

نصّ «ما لم يُقفل بهذا البند» في `docs/decisions/ADR-0026-kernel-confinement.md` يقول: «لم تُشغَّل الدولةُ في حاويةٍ فعليّة داخل هذا المستودع — لا docker فيه ولا مُشغِّل حاويات». وهذا لم يعد صحيحًا: شاهد الحصر داخل الحاوية قائمٌ في CI منذ W-2026-035 (T-124). ولكنّ هذا الملف محجوزٌ ببندٍ حيٍّ (W-2026-039)، فلا يُلمس هنا. يُوثَّق تقادمُه هنا لمن يملك فكَّ الحجز.

## §2 — الإصلاح

```javascript
// قبل
const N = 1000000; // السقف السكاني المعلن في config/scale.yaml

// بعد
const N = s.scaleConfig.policy.population_max; // السقف السكاني المعلن في config/scale.yaml — يُقرأ من التهيئة لا يُثبَّت (W-2026-061)
```

`boot()` يستدعي `bootstrapState()` التي تقرأ `config/scale.yaml` وتُعيد `scaleConfig.policy.population_max`. فالمسبار الآن يقيس عند السقف المعلن في التهيئة، أيًّا كان.

## §4 — ما هذا الإصلاح لا يفعله

- **لا يُرقّي C-17** — حكم المدقّق (RULE-004). المسبارُ يقيس الآن عند السقف المعلن، ولكنّ المراجعَين ذكرا أربعةَ موانع، و«المسبارُ يقيس عند مليون» واحدٌ منها. والبقاءَ ثلاثة: حاويةٌ حقيقية، قياسٌ مستقل، زمنُ التوزيع.
- **لا يُرقّي C-09** — حكم المدقّق (RULE-004).
- **لا يُصلح نص ADR-0026** — محجوزٌ بـW-2026-039.
- **لا يُغيّر عدد الاختبارات** — المسبارُ أداةُ تدقيقٍ (.mjs) لا اختبار قبول.
- **لا يُغيّر نسبة الإنجاز** — 97.00% كما هي، والفجواتُ سبعٌ كما هي.
