# ADR-0001: صفر تبعيات تشغيل خارجية

> **القاعدة الحاكمة RULE-000:** وثّق كل ما قمت به واترك ما تبقّى. النص: `../../GOVERNING_RULE.md`

- **التاريخ:** 2026-08-21
- **الحالة:** معتمد تقنيًا، ينتظر الاعتماد الملكي
- **المالك:** القيّم على المستودع

## السياق
النواة السيادية تتعامل مع المفاتيح والتوقيع وسجل التدقيق. أي تبعية خارجية توسّع سطح الثقة
وسلسلة التوريد، وتخالف روح «لا مسار جانبي».

## القرار
النواة تستخدم `node:crypto` و`node:fs` فقط. لا تبعيات تشغيل. TypeScript وأنواع Node أدوات بناء فقط.
حتى محلّل YAML كُتب داخليًا لمجموعة فرعية آمنة بلا مراجع أو وسوم.

## البدائل المرفوضة
- مكتبة YAML جاهزة: سطح خطر أوسع لملف تهيئة سيادي.
- إطار تشفير خارجي: `node:crypto` يكفي لـ Ed25519 و SHA-256.

## الأثر
- سرعة بناء واختبار عالية، ومراجعة أمنية أبسط.
- تكلفة: نكتب أدوات صغيرة بأنفسنا ونختبرها (تم: اختبار المحلّل).

## بديل مستقبلي
إذا احتجنا YAML كاملًا، يُعتمد بقرار ADR جديد وبمراجعة أمنية موثّقة.
