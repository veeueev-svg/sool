# ADR-0002: بوابة التاج نقطة اعتماد واحدة لا تنفّذ

> **القاعدة الحاكمة RULE-000:** وثّق كل ما قمت به واترك ما تبقّى. النص: `../../GOVERNING_RULE.md`

- **التاريخ:** 2026-08-21
- **الحالة:** معتمد تقنيًا، ينتظر الاعتماد الملكي
- **المالك:** حرس التاج

## القرار
`CrownGateway.authorize()` هي **نقطة الاعتماد الوحيدة**، وهي **لا تنفّذ** شيئًا: تعيد قرارًا مع سبب
و`auditId`. التنفيذ عند `CrownGuard` وغيره. هذا يفرض RULE-004 بنيويًا لا بالنصيحة.

## نتائج مقصودة
- استحالة «الاعتماد الذاتي»: من ينفّذ لا يعتمد.
- كل قرار — سماحًا أو رفضًا — له سجل حقيقي قابل للتتبع.
- إضافة أي وحدة جديدة تمرّ من البوابة، وأي مسار مباشر يُرفض ويُسجَّل (`attemptSideChannel`).

## أثر على القادمين
عند بناء أي وحدة سيادية جديدة: استدعِ `authorize()` أولًا، ولا تكتب فحص صلاحية محليًا موازيًا.
