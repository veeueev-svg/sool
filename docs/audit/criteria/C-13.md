# C-13 — نموذج غير موقّع أو غير مُقيَّم لا يُشغَّل

- الحكم: **اكتُفي بتقرير المنفّذ**
- السند:
  - السند المقروء: [`docs/test-reports/phase-16-18.md`](../test-reports/phase-16-18.md) §1–3 — مصدرٌ غير معلن أو توقيعٌ غريب أو بصمة شريحة مخالفة تُرفض، والنموذج يُسجَّل محجورًا ولا يُنشَّط بلا اعتماد ملكي.
  - **الفجوة:** محرّك استدلال حقيقي وحالات سلامة جدّية — بندٌ T-21. وقبل إغلاقه لا يصحّ الحكم بالاستيفاء.

- أعاد المدقّق القياس بنفسه: لا — المعيار يشترط ألّا يُشغَّل نموذجٌ غير موقَّع، ولا محرّك استدلال حقيقي في المستودع بعد، فما يُقاس اليوم هو الحجر لا التشغيل
- البند المفتوح إن كان فجوة: T-21
