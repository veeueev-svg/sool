4) اختبارُ الطفرة — قياسُ قوّةِ التأكيد لا قياسُ نجاحِه
==============================================================
الدعوى المرادُ إثباتُها: الاختبارُ الأوّل يُمسك بموضعِ الحرَس، لا بوجودِ الرمز.
الطريقة: أُبدِل في src/composition/sovereignty.ts السطرُ

    const deployCensus = guardDeployDeclaration(options.deployDir);

بقياسٍ أصفارٍ لا يحرس شيئًا:

    const deployCensus = { root: "", dirs: 0, files: 0, bytes: 0, names: [] };

ثمّ أُعيد البناءُ وشُغِّل ملفُّ الاختبار وحدَه. النتيجةُ المقيسة:

    not ok 1 - نفخُ إعلانِ النشر يُردّ قبل بناء الدولة — والشاهدُ ملفُّ سجلٍّ لم يُكتب
    ok 2..7 (الستةُ البواقي)
    # pass 6
    # fail 1
    error: 'Missing expected exception.'

الدلالةُ: الاختبارُ الأوّل هو المُمسِكُ وحدَه بالنداء — فلو حُذف الحرَسُ لسقط وحدَه.
واستُعيد الملفُّ الأصليُّ بعد القياس، وأُعيد البناءُ والتشغيلُ (2075/2075).

وما لم يُقس فيُعلَن: هذه الطفرةُ تُثبت **وجودَ الحرَس في مسار السيادة**، ولا تُثبت
النقيضَ التاريخيَّ (أنّ الشفرةَ قبل البند كانت تكتب السجلَّ ثمّ تسقط). فإثباتُ النقيض
يقتضي نفخَ deploy/ الفعليِّ في المستودع — وهو ممنوعٌ لأنّه يُسقط كلَّ اختباراتِ النشر
معه، وهو عينُ ما وقع في W-2026-004. فالمقيسُ: الرفضُ يسبق كتابةَ السجل. والمقروءُ
بنيةً في src/index.ts:89: كتابةُ السجل تسبق composeOperations. ومنهما يلزم المدّعى.
