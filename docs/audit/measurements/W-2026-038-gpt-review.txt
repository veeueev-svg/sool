## RESIDUAL DEBT

- `C09_DNS_POLICY_DEPENDENCY`: Even if the IPv6 blind spot is corrected, the declared-counterparty path depends on Cilium `toFQDNs`, while the Compose path denies all egress. A production deployment compatibility test and a raw socket/DNS test against both an allowed and a forbidden destination should be retained as a separate follow-up.
- `C09_CI_PROVENANCE_WEAKNESS`: The container evidence is a copied human-readable output carrying a run number and commit label, not the CI job definition, immutable image digest, or original machine log. This did not create the primary verdict because the supplied source already contains a blocking coverage defect.
- `C11_TTL_AND_ROLLBACK_STRESS`: The package reports that an expired reservation cannot be committed, but does not show the full factory's rollback behavior when work completes after expiry or fails between entity creation and commit. This needs an end-to-end delayed-commit fault test even after a shared reservation store exists.
- `C13_ASYNC_TIMEOUT_GAP`: The inference engine accepts only a synchronous callback and checks elapsed time after the callback returns. It cannot interrupt a blocking callback, and the ADR admits that an asynchronous real model needs different measurement. A real-runtime adapter needs enforceable cancellation/deadline behavior.
- `C13_ATTESTATION_PERSISTENCE`: The supplied engine stores runtimes and attestations in process-local maps. Evidence of restart behavior and revocation propagation for real model runtimes is absent.
- `C12_UNBOUNDED_HISTORY`: `ChannelBus.accepted`, `CollusionDetector.interactions`, `CollusionDetector.findings`, and the covert detector's `raised` set grow without a demonstrated bound. The covert trace list is window-pruned, but the other collections are not.
- `C08_FSYNC_COST`: The supplied ADR reports per-record fsync costs reaching about 4.34 ms and p99 around 100.4 ms, but the actual cost measurement is absent. Durability latency and backpressure should be treated as operational debt once correctness is demonstrated.
- `C08_JOURNAL_CRASH_ATOMICITY`: The journal writes JSON plus a newline and then calls fsync, but the supplied source has no recovery rule for a torn final write. `readInternal()` treats any malformed final line as fatal. A crash during the write can therefore make the entire state unbootable; truncation-to-last-verified-record or another atomic record format needs explicit design and tests.
- `C17_CAPACITY_HEADROOM`: Even under the temporary three-million configuration, the worst maximum latency was 24.211 ms against a 25 ms limit in only three runs. More repetitions, noisy-neighbor conditions, and production-equivalent hardware are needed before relying on that tail margin.
- `C17_BULK_LOAD_TIME`: Three-million population distribution took approximately 193–210 seconds. The criterion's latency wording should explicitly state whether initialization/rebalancing time is excluded from the response threshold; otherwise this is unresolved debt rather than a metric that can be silently omitted.
