2) ما أُخرج — وحدُّ القسمة هو ثابتُ الملف الرابعُ نفسُه
────────────────────────────────────────────────────────────────────
الملفُ كان يجمع في مسارٍ واحدٍ:
  (أ) إعلانٌ لا يُنفَّذ منه سطر   — ستُّ أشكالٍ وهويّةُ المفتّش المعلنة
  (ب) **مَن يُنتج**              — يستهلك مخزونًا ويستأجر حصةً ويكتب قيدَ تدقيق
  (ج) **مَن يشهد على المُنتَج**   — يقرأ التقريرَ ويحكم: لا سجلَّ ولا حالةَ ولا وقت

وثابتُ الوحدة الرابع نفسُه يقول: «**المشغّل لا يفتّش** (RULE-004)» — فكان الملفُ يعلن
حدًّا ويسكن طرفَيه. فأُخرج الحكمُ إلى ملفٍ **لا يستورد سجلَّ التدقيق أصلًا**.

نصوصُ أسباب الرفض **وترتيبُ فحصها** مصونةٌ حرفيًّا (وهي عقدٌ تقرؤه الاختبارات):
  دفعة بلا معرّف معلن → دفعة قائمة بهذا المعرّف → الإنتاج للمشغّل المعلن وحده →
  منشأة غير قائمة → منشأة غير موجودة → نوع المنشأة غير معلن → الدفعات المتزامنة بلغت الحدّ
  → لا إنتاج بلا مدخلات → مدخل غير معلن → مدخل معلن غائب → مدخل غير مُقاس →
  المقدَّم يتجاوز المخزون → المدخل لا يكفي دفعةً واحدة → الفقد المعلن غير صالح →
  حصة المورد مرفوضة → تعذّر استهلاك مدخل
  دفعة غير قائمة → دفعة مقفلة أو ملغاة → لا إقفال بلا تقرير تفتيش → التفتيش لجهة معلنة
  غير المشغّل → تقرير بلا قائمة فحوص → نوع المنشأة غير معلن → **فحص غير معلن** →
  **فحص مكرَّر** → **دعوى تخالف قيد النظام**
والقيودُ: production_started · production_refused · production_completed ·
  production_rejected · production_aborted · quality_claim_contradicted — بأسمائها.

ما **لم** يُنقل، وبيانُه:
  - `complete` بقيت في الصنف: هي **تُقفل الدفعة** وتُحرّر الحصة وتُدخل المخرجَ المخزون
    وتكتب أربعةَ قيود — فهي فعلٌ لا شهادة، وإنّما استُخرج منها **الحكمُ** وحدَه.
  - `refuse` بقيت في الصنف: الرفضُ **يكتب** `production_refused`.
  - `start` و`abort` و`sweep` بقيت: كلُّها تستهلك أو تُحرّر وتكتب قيدًا.
  - قراءةُ `resources.activeLeases(now)` بقيت في الصنف: هي **قياسٌ** للقيد، والدالّةُ
    النقيّةُ تتلقّى نتيجتَه (`leaseActive`) ولا تقرأ سجلًّا بنفسها.
