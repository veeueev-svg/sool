## 3) السبب الجذري المقيس (SIGPIPE تحت pipefail)

نمطُ العيب في `scripts/check_declaration.sh` السطر 172:

```bash
elif printf '%s
' "$closed_ids" | grep -qx "$t"; then
```

والملف يفتتح بـ`set -euo pipefail` (سطر 53). عند إيجاد `grep` التطابق يخرج فورًا؛ `printf` يتلقى SIGPIPE فيخرج بـ141؛ `pipefail` يجعل أنبوبًا كاملًا برمزٍ غير صفري؛ شرطُ `elif` يقيَّم خاطئًا ⇒ يسقط إلى فرع `else` فيطبع `[DC-04] معرَّفٌ بلا صفٍّ` بلا سببٍ حقيقي. لا يقع إلا حين يجد `grep` التطابق قبل أن تنتهي `printf` من الكتابة — وذل كأرجحُ تحت الحمل المتزامن.

**إعادة الإنتاج النقية (بلا السكربت كله):**

```bash
set -euo pipefail
closed_ids="$(printf 'T-16
T-21
T-23
T-31
T-110
')"
for t in T-16 T-21 T-23 T-31 T-110; do
  if printf '%s
' "$closed_ids" | grep -qx "$t"; then :; else echo "DC04_MISS:$t"; fi
done
```
