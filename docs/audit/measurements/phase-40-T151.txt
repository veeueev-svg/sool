قراءةُ الشفرةِ والبيئة:
  .git/hooks           : لا خطّافَ فعّالًا (لا شيءَ غيرَ *.sample)  ⇒ git push بلا فحص
  push.sh              : لا ينادي git push — blobs ⇒ tree ⇒ commit ⇒ PATCH ref بـcurl
                         ⇒ خطّافُ pre-push لا يُستدعى في هذا الطريقِ قطعًا
  push.sh (قبل العمل)  : يقرأ open(p,'rb') من شجرةِ العمل لا من HEAD

تجربةُ الشجرةِ غيرِ النظيفة (لُمس version.json بلا التزام، ثمّ أُعيد):
  sha256(شجرةُ العمل) = 939f4a7bf19023a5…      ← وهذا هو المدفوع
  sha256(HEAD)        = 4d59e6bce9aff328…      ← وهذا وحدَه ما حكمت عليه الحواجز
  git status --porcelain = "M version.json"    ⇒ العلّةُ مرئيّةٌ لو سُئل عنها

## (د) الخطّافُ يُقاس بدفعٍ حقيقيّ لا بوجودِ ملفّ
  git init --bare /tmp/bare.git ثمّ git push /tmp/bare.git main مع شجرةٍ غيرِ نظيفة:
    خرجُ الخطّاف : ✗ [PG-01] … ثمّ "✗ خطّافُ pre-push: حارسُ الدفعِ منع"
    خرجُ git     : error: failed to push some refs to '/tmp/bare.git'   ⇒ exit 1
    حالُ البعيد  : "your current branch 'master' does not have any commits yet"
                   ⇒ لم يصل مرجعٌ ولا جِرمٌ. المنعُ فعلٌ لا كلام.
  وحدٌّ قيس: git push إلى البعيدِ الحقيقيّ (origin) يسقط على الاستيثاقِ **قبل** الخطّاف
    ("could not read Username for 'https://github.com'") ⇒ فلا يُقاس الخطّافُ من هناك،
    ومن قاسه بذلك ظنَّ الخطّافَ عاملًا وهو لم يُستدعَ.
