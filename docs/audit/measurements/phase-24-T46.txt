2) الأبوابُ الثلاثةُ: قياسُ إغلاقِها لا الادّعاء
════════════════════════════════════════════════════════════════════════

الحالةُ المطلوبةُ لا يُنتجها بابٌ من أبوابِ الدولة. وهذا مقيسٌ لا مفترض:

[DR-01] governors.propose({regionId:'region:ghost'})
        → ok:false · السبب: «إقليم غير قائم»
        (src/federation/governor.ts: `if (!this.deps.regions.isActive(...))`)
        → seatedRegions().length = 0

[DR-02] propose('region:research') → approve(أمرٌ ملكي)
        → revokeDelegation ok:true → dissolve ok:true  (المقعدُ خالٍ فلا يمنعُه حاكم)
        → execute → ok:false · السبب: «إقليم غير قائم»
        فنافذةُ ما بين الاعتمادِ والتنفيذِ محروسةٌ أيضًا (فحصٌ ثانٍ عند التنفيذ).
        → seatedRegions().length = 0

[DR-03] seat('region:research') → revokeDelegation → dissolve
        → ok:false · السبب: «حاكم جالس: يُعزل بمساره المعلن أولًا»
        → isActive('region:research') = true (الرفضُ لا يغيّر الحالة)

النتيجة: البابُ الأماميُّ مغلقٌ بثلاثةِ أقفال. فالانحرافُ إن وقع فمن تباعدِ
سجلَّين لا من فعلٍ مشروعٍ واحد — ولذلك يُحقَن في التركيبِ صريحًا.

3) الحقنةُ الصريحة [DR-04]
════════════════════════════════════════════════════════════════════════

الطريقة (كلُّها عبر الواجهةِ العامّة `src/index`، بلا لمسِ سطرٍ في src/):

  seat('region:research','official:noor')      // بالمسارِ المعلن: ترشيح+أمرٌ ملكي+تنفيذ
  seatedRegions().length = 1                    // المقعدُ مشغولٌ حقًّا

  blindRegions = new RegionRegistry({ audit, gateway, declaredRegions:[...] })
  blindRegions.bindGovernorProbe(...)
  blindRegions.isActive('region:research') = false   ← الحقنةُ واقعةٌ لا مفترضة

  driftedMonitor = new RegionMonitor({ regions: blindRegions, governors: s.governors, ... })
  driftedMonitor.sweep(T0 + 1000)

وهو تباعدُ سجلَّين كالذي يقع بإرجاعِ (restore) أحدِهما دون الآخر — أي الوجهُ
نفسُه الذي قِيس في T-54 على الدفتر: بابانِ لحالةٍ واحدةٍ لا يتّفقان.

الخرجُ المقيس:
  flags(kind='governor_without_region').length = 1
  regionId  = 'region:research'
  severity  = 'high'
  detail    = «حاكم جالس في إقليم غير قائم: official:noor»   ← يُسمّي الحاكمَ لا يُبهمه
  لا مهلةَ سماحٍ لهذه المخالفة: ترتفع عند T0+1000 لا بعد VACANCY
  سجلُّ التدقيق: `region_flagged` +1 · actor = REGION_AUDITOR
  audit.verifyIntegrity().valid = true

4) حدُّ سلطةِ المراقب [DR-05]
════════════════════════════════════════════════════════════════════════

driftedMonitor.contain(GOVERNOR_EXECUTOR,'region:research','governor_without_region',...)
  → ok:false · السبب: «إقليم غير قائم»
  → killSwitch.status.engaged = false

فالمراقبُ يرفع ولا يعالج (ثابت 1)، والاحتواءُ لا يجد إقليمًا يحتويه. وهذه
حدودٌ صادقةٌ لا عطب: علاجُ «سلطةٍ بلا إقليم» عزلُ الحاكمِ بمسارِه المعلن،
وهو بابُ `governors` لا بابُ `regionMonitor`.
