# السؤال: البندُ T-122 أدام الدفترَ والعقودَ والسكان، وأعلن أنّ الوحداتِ المشتقّة تبقى فجوةً
#         باسم T-125. فما تفقده هذه الوحداتُ فعلًا عند إعادة التشغيل، وما أثرُ الفقد على
#         **قدرةِ الدولة على الفعل** لا على تقريرها؟ وكم يكلّف الإغلاق؟
# طريقةُ القياس: مهادٌ واحدٌ يُقلَع مرّتين في **جريانٍ واحد**، فالمقارنةُ تُقاس ولا تُستدعى
#         من ذاكرة. الجريانُ الأول بنطاقِ ما بعد T-122 حرفًا (عشرةُ أصناف)، والثاني بالنطاق
#         الكامل المعلن في config/persistence.yaml (تسعةَ عشر). والنطاقُ يُبدَّل في نسخةِ
#         التهيئة في مجلدٍ مؤقّت لا في الشفرة (RULE-005).
# البذرةُ متطابقة: إصدارُ 100,000,000 وحدة وحرقُ 4,000,000 · بندُ موازنةٍ سقفُه 60,000,000 ·
#         صرفُ 1,500,000 · جبايةٌ على 2,000,000 قُدِّرت وحُصِّلت · حسابٌ خارجيٌّ مفتوح ·
#         دفعةُ 300,000 · تقديرُ خطرٍ وخرقٌ واحد.
#
# ═══ الخلاصةُ في سطرين ═══
# قبلَ الإغلاق: **كلُّ قيمةٍ تعود صفرًا** بلا استثناء، وأخطرُ من ذلك أثران:
#   (1) الصرفُ يصير **مستحيلًا** بعد الإقلاع («لا صرف بلا بند موازنة قائم»)، فالدولةُ تُشلّ.
#   (2) البندُ يُعاد إعلانُه بسقفٍ كاملٍ 60,000,000 والدفترُ يشهد بصرفِ 1,500,000 — أي أنّ
#       **إعادةَ التشغيل تُعيد تعبئةَ السقف**، فتُخلق قدرةُ صرفٍ من العدم ويتناقض الشاهدُ
#       مع الحالة. وهذا ليس نقصَ تقريرٍ بل خللٌ في الحرَس نفسه.
# بعدَ الإغلاق: كلُّ قيمةٍ تنجو بلا فقد، و`silent` فارغة، والصرفُ الجديد مقبولٌ بمعرّفٍ
#   لا يتصادم (`disb:4`)، وإعلانُ البند ثانيةً **مرفوضٌ** لأنّه قائم — والسقفُ لا يُعبَّأ.
#
# ═══ الكلفةُ مقيسةٌ لا مقدَّرة ═══
#   قيودُ اليوميّة: 73 ⇒ 87 (+14 قيدًا، +19.2%)
#   حجمُ اليوميّة: 41,372B ⇒ 47,801B (+6,429B، +15.5%)

#   زمنُ الإقلاع مع الإرجاع: 16ms ⇒ 19ms (+3ms) · تحقُّقُ السلسلة: 1ms ⇒ 2ms
#   والكلفةُ محدودةٌ بطبعها: هذه أفعالٌ سياديّة معدودة (أمرٌ ملكيٌّ لكلِّ إصدارٍ وبند)،
#   لا دفعاتُ سكانٍ بالآلاف — فنموُّها بعددِ القرارات لا بعددِ الوكلاء.

# ═══ انحرافٌ يُعلن (RULE-008) ═══
#   اليوميّةُ تنمو نموًّا **محدودًا** بكلِّ إقلاع: سبعةُ قيودِ `audit_entry` لسبعةِ أبوابِ
#   إرجاعٍ تُقيّد استعادتَها في السجل الأبديّ (RULE-006)، والسجلُّ مُدوَّنٌ منذ T-27.
