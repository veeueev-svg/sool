# تقارير الحوادث — `docs/incident-reports/`

> **RULE-006 — سجّل كل شيء.** الحادثة التي لا تقرير لها لم تُعالَج، وإن أُصلحت.

فارغ الآن بقصد (RULE-001): لم تقع حادثة تشغيل حقيقية بعد. المجلد أُنشئ في ورشة الهيكلة
(0.24.0) لأن [`docs/PHASE_PROCEDURE.md`](../PHASE_PROCEDURE.md) §5 كان يوجب الكتابة فيه
وهو غير موجود — فكان الإجراء يحيل إلى مسارٍ لا وجود له.

- **المالك:** المشغّل، وتُراجعه بوابة التاج.
- **الاسم:** `<YYYY-MM-DD>-<اسم-قصير>.md`.
- **الكتاب الذي يُنفَّذ عند الحادثة:** [`docs/runbooks/incident-response.md`](../runbooks/incident-response.md)،
  ومعه [`halt-and-recover.md`](../runbooks/halt-and-recover.md) إن بلغت الحادثة حدّ الإيقاف.

## الصيغة الدنيا

| الحقل | المطلوب |
|---|---|
| متى كُشفت | الطابع الزمني ومن كشفها: ماسحٌ أم بشر (وإن كشفها بشرٌ فذاك عيبٌ في المراقبة يُعلن بندًا) |
| الصنف والشدّة | صنفٌ من `PRODUCTION_KNOWN_INCIDENTS`، وشدّةٌ لا تُخفّف لتمرّ |
| ما فُعل | الخطوات بترتيبها، وأرقام سجلات التدقيق (`auditId`) المرافقة |
| السبب الجذري | لا «خطأ بشري» وحده: ما الذي سمح للخطأ أن ينفذ |
| البند المفتوح | `T-<رقم>` في `PROGRESS.md` §2 إن بقي شيءٌ غير مُغلق |
