# الأوامر الملكية

> **القاعدة الحاكمة RULE-000:** وثّق كل ما قمت به واترك ما تبقّى. النص: `../../GOVERNING_RULE.md`

كل أمر ملكي (اعتماد مرحلة، نقض، إيقاف، تفويض، إعلان تشغيل) يُسجَّل هنا في ملف باسم:
`YYYY-MM-DD-<الرقم>-<الموضوع>.md` ويتضمن:

```
الرقم:
التاريخ:
المُصدِر: الملك
الموضوع:
النص:
الأثر على المراحل:
معرّف السجل في سلسلة التدقيق (auditId):
```

**بند مفتوح:** لا يوجد أمر ملكي مسجَّل بعد. المرحلة 1–10 منفَّذة تقنيًا وتنتظر **أمر اعتماد ملكي**
لتثبيت نسبة 17% رسميًا (`version.json` → `royal_approval: pending`).
